# 外卖搜索广告校准模型的LLM文本建模：双路transformer与三重loss对齐文本与ID表征

## 筛选与速览

- **一句话速览**：在 [[外卖搜索广告生成式混排一期：用自回归生成与DPO偏好对齐替代贪心混排]] 的校准模型上引入 LLM 文本表征——ID 与文本两路对称 transformer 编码上下文，用**辅助 CTR loss**（独立梯度信号加速文本侧收敛）和**带 stop-gradient 的 InfoNCE 对比 loss**（文本空间单向向 ID 空间靠拢）解决目标不一致、收敛不一致、空间不一致三大业界难题，离线 AUC 累积 +0.5pp，线上收入 +1.04%（非首位 +1.78%），推全预计 +10.4 万/天，耗时仅 +3.3ms。
- **最有价值的部分**：一是把「LLM 表征进 CTR 模型」的三个业界挑战与解法做了系统化映射，且每个解法都做了消融验证（辅助 loss 单独 +2.6 千分点、对比 loss 单独 +2.9 千分点、叠加 +3.2 千分点，收益部分重合但保留两者）；二是 stop-gradient 的方向选择论证——只让文本向 ID 靠拢而不反向，理由是 ID 侧有精排 pCTR 强特征且收敛快，反向更新会把 ID 表征拉偏，这个设计决策比 loss 本身更有迁移价值。
- **与我研究主线的关联**：这是大模型与推荐系统结合在广告混排链路的最小切口落地——不动生成模型，只增强校准模型的语义表征，用排序质量的提升间接传导到生成序列质量。

## 背景与问题

外卖餐饮搜索广告混排已升级为生成式混排，当前混排模型包括两部分：**校准模型**（捕获候选广告和自然结果的整体信息，对精排 pCTR 校准，输出更准的分位次 pCTR）和**生成模型**（输出最终广告 poi 序列）。整体训练流程：预训练阶段校准模型预估候选 poi 每个位次的 pCTR 传入生成模型联合训练；偏好对齐阶段用该 pCTR 计算 reward 筛选优劣样本对做 DPO 更新生成模型。

![[99_Attachments/图片/km-2770912374/混排整体训练流程图.svg]]

校准模型基线结构：输入广告自身特征和上下文广告与自然特征，经 MLP 输出分位次 CTR，主要依赖 **ID 类特征**（poiid、类目 id）和**预估值类特征**（精排 pCTR、pCVR），语义理解层面存在明显短板：

![[99_Attachments/图片/km-2770912374/校准模型基线结构图.svg]]

LLM 文本 Embedding 的三方面优势：① **长尾/冷启动友好**——基于文本内容生成，不依赖历史交互数据；② **捕捉 query-item 语义相关性**——搜索场景下直接度量用户意图与 item 内容的匹配程度；③ **提升候选区分度**——提供更丰富的 item 内容表征，感知候选集内 item 间的相对语义差异。

## 业界相关工作

### 核心挑战

1. **文本表征与 CTR 任务优化目标不一致**：通用 LLM 预训练是 NTP 语言理解任务，embedding 编码内容层面的语义相似性；CTR 模型依赖用户行为驱动的协同信号——语义相近的两个 item 用户交互模式可能截然不同；
2. **ID 与文本表征收敛速度不一致**：ID 表征是查表式记忆学习，信号集中、收敛快；文本表征通常冻结 embedding、更新共享编码器，属泛化式学习、收敛慢。联合训练时 ID 侧快速收敛后主导 loss 下降方向，文本侧欠拟合或梯度被淹没；
3. **ID 与文本表征空间不一致**：即使优化目标对齐，两路表征在维度、分布和几何结构上差异显著，直接拼接融合时下游网络需承担跨空间映射压力。

### 业界解法与本次选型

| 挑战 | 业界方法 | 本次选型 |
| --- | --- | --- |
| 目标不一致 | 协同信号任务对齐：QARM (2024)、MIM (2025)、LEMUR (2025) 用行为信号监督 | 直接复用外卖搜精排已做的用户行为对齐（LLM 文本建模二期） |
| 收敛不一致 | 文本表征预训练（SimTier：先纯文本表征预估 CTR 预训练再入主模型）；文本表征 ID 化（QARM：量化为离散 Semantic ID） | 简化为文本编码器接**辅助 CTR loss**，无需额外训练阶段即保持文本侧独立预测能力 |
| 空间不一致 | 独立建模再融合（MUSE：分别算 ID/多模态相似度加权融合；SimTier：多模态相似度离散化为直方图特征）；显式空间对齐（RecGOAT：对比学习单点对齐 + 最优传输分布级对齐） | 结构上两路**独立建模再融合** + 损失上引入**对比学习 loss** 显式拉近 |

## 技术方案

### 整体架构

给定同一请求下的候选广告与自然 item 集合，模型为 **ID 与文本两路并行的上下文建模通路**：ID 通路将 ID 类特征与预估值特征输入 transformer encoder 输出 ID 侧上下文表征；文本通路将 LLM 文本 embedding 输入另一 transformer encoder 输出文本侧上下文表征。两路表征与精排 pCTR 在特征层拼接后送入主 MLP，输出分位次 pCTR。训练损失 = 主 CTR loss + 辅助 CTR loss + 对比学习 loss。

![[99_Attachments/图片/km-2770912374/校准模型LLM文本建模架构图.svg]]

### ID 与文本上下文模块

两路结构对称、参数独立。以文本通路为例：同一请求下候选广告与自然 item 的文本 embedding 拼接为序列，输入 transformer encoder，self-attention 捕捉候选集内 item 间的语义差异与相互关系，输出每个 item 的文本侧上下文表征 $h_i^{\text{text}}$；ID 通路结构相同输出 $h_i^{\text{id}}$。

**离线消融**（AUC）：

| 模型版本 | AUC | AUC diff |
| --- | --- | --- |
| base | 0.8057 | |
| 使用 ID 上下文 transformer 替换 MLP 建模 | 0.8065 | +0.0008 |
| ID 上下文 transformer + 文本上下文 transformer | 0.8075 | +0.0018（累积） |

### 辅助 CTR loss

对文本上下文模块输出 $h_i^{\text{text}}$ 单独接轻量 MLP 输出辅助 pCTR，以与主任务相同的点击 label 计算交叉熵 $\mathcal{L}_{\text{aux}}$，为文本编码器提供**独立梯度信号**加速收敛。离线尝试过对文本表征模块预训练，效果与辅助 CTR loss 相仿，为减少训练流程复杂度选用后者。

### 对比学习 loss

**正负样本构造**：同一请求下 item $i$ 的 $(h_i^{\text{text}}, h_i^{\text{id}})$ 构成正样本对；同请求内其他 item 的文本表征 $\{h_j^{\text{text}}\}_{j\neq i}$ 为负样本，侧重建模请求内的相对区分能力。

**Stop-gradient 设计**：loss 梯度仅反传至文本编码器，对 ID 编码器输出施加 stop-gradient，对齐方向单向（文本空间向 ID 空间靠拢）。理由：ID 类特征在 CTR 任务上收敛更快且有精排 pCTR 强特征，若允许对比 loss 同时更新 ID 编码器，ID 表征会被文本语义空间反向拉偏，破坏已学到的行为模式。

**Loss 形式**：InfoNCE + cosine 相似度，温度超参 τ 控制分布平滑程度：

$$
\mathcal{L}_{\text{cl}} = -\frac{1}{N}\sum_{i=1}^{N}\log\frac{\exp\left(\text{sim}(h_i^{\text{text}},\ \text{sg}(h_i^{\text{id}}))/\tau\right)}{\sum_{j=1}^{N}\exp\left(\text{sim}(h_i^{\text{text}},\ \text{sg}(h_j^{\text{id}}))/\tau\right)}
$$

总训练 loss 加权求和（α、β 为超参）：

$$
\mathcal{L} = \mathcal{L}_{\text{main}} + \alpha\cdot\mathcal{L}_{\text{aux}} + \beta\cdot\mathcal{L}_{\text{cl}}
$$

**离线消融**：两个 loss 收益部分重合——辅助 CTR loss 通过点击 label 直接监督文本编码器，对比 loss 通过拉近空间距离让文本侧间接继承 ID 侧的 CTR 模式，因此不完全等价，最终两个都保留：

| 模型版本 | AUC | AUC diff |
| --- | --- | --- |
| 只用主 CTR loss（上节最终版本） | 0.8075 | |
| +辅助 CTR loss | 0.8101 | +0.0026 |
| +对比学习 loss | 0.8104 | +0.0029 |
| +辅助 CTR loss + 对比学习 loss | 0.8107 | +0.0032 |

最终所有优化（两路 transformer + 两个 loss）一起带来 **AUC +0.5pp**（0.8057→0.8107）。

## 线上效果与分析

线上 20% 流量实验，20260430~20260506 共 7 天，影响范围：外卖餐饮搜索浮动位广告（slot=420）。

- **整体**：广告收入 +1.04%，曝光 +1.31%，CPM -0.27%，CTR -0.29%，ROI -0.36%，UVRPM -0.09%，预期全量后广告收入 +10.4 万/天；
- **首位**：效果持平（「首位求交」逻辑，本次迭代无法影响首位，符合预期）；
- **非首位**：广告收入 +1.78%，曝光 +1.49%，CPM +0.29%，CTR +0.25%，ROI -0.32%。

**收益来源分析**：收入提升来自曝光增加和排序效果提升。校准模型预估更准使生成序列更优，大盘曝光提升后 CTR 没有明显下降——单纯提升曝光时 CPM 和 CTR 会明显下降，收入与曝光提升幅度的兑换比约 1:4；线上另一组将大盘曝光调整到 -0.44% 时，大盘整体收入 +0.61%、非首位收入 +1.17%，即排序收益在缩曝光下仍然成立。考虑到 UVRPM 持平、广告曝光小幅增长对用户体验无影响、adload 20% 不算高，推全曝光增长实验组。

## 性能影响

外卖搜二调整体耗时（午高峰）：基线 avg=17.9ms、tp99=31.1ms；实验组 avg=21.2ms、tp99=34.4ms——avg 和 tp99 均增加 3.3ms，增长较少。

> 美团内部 Launch Review 文档（外卖餐饮搜索 slot=420 单场景、7 天 20% 流量），数据不可复现、未独立复核。几个值得追问的点：① 「文本表征与 CTR 目标对齐」直接复用精排侧的用户行为对齐成果，本篇未独立验证该对齐在混排校准任务上的适配度；② ROI -0.36%、UVRPM -0.09% 的稀释未做拆分归因；③ α、β 超参取值及敏感性未披露；④ 消融均在同一离线数据链上进行，离线 AUC 增益（+0.5pp）到线上收入（+1.04%）的传导关系只有单一实验支撑。原文含合并单元格表格，本笔记为简化转写，完整结构以学城原文为准。

# Generative recommendation profile

Use this profile for developments in generative recommendation and adjacent areas: LLM-based recommenders, generative retrieval and ranking, semantic IDs and tokenized item representations, LLM user modeling, controllable and conversational recommendation, RAG applied to recommendation, recommendation-oriented agents, and new datasets, benchmarks, or evaluation protocols for these areas.

Typical items include research papers, model and framework releases, industry deployments, benchmark results, insightful technical analyses, and community discussions with practical substance.

Do not use this profile for content whose primary value is general LLM news without a recommendation or retrieval angle, finance-first market coverage, routine updates without technical substance, or promotional material.

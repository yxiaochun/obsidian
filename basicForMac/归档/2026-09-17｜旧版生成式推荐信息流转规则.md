# 生成式推荐知识库信息流转规则

本库服务于「生成式推荐」方向的研究与输出，覆盖大模型与推荐系统结合、生成式召回/排序、可控内容生成、推荐评测等主题。所有信息按「进入 → 检查 → 分类 → 复盘 → 输出」五个环节流转。

## 一、信息进入

信息统一从 `00_Inbox` 进入，先收集、后处理，不做当场判断。

| 来源 | 去处 |
| --- | --- |
| arXiv（cs.IR / cs.CL / cs.LG 交叉）、Google Scholar 订阅 | `00_Inbox/自动抓取` |
| RecSys、SIGIR、KDD、WWW、CIKM 等会议论文与演讲 | `00_Inbox/自动抓取` 或手动剪藏 |
| GitHub Trending 中推荐系统、LLM 应用相关项目 | `00_Inbox/自动抓取` |
| 行业博客与新闻（Meta / Google / Netflix / Amazon Science、国内大厂技术博客等） | `00_Inbox/手动剪藏` |
| 微信公众号、小红书、知乎等社媒内容 | `00_Inbox/手动剪藏`，保留原文链接 |
| 灵感、临时想法、待办问题 | `00_Inbox/手动剪藏`，一句话记录即可 |

进入规则：

- 剪藏和抓取内容保持原样，不改写、不总结，摘要和判断放到后续分类环节。
- 剪藏必须带来源链接和原始日期，无来源的信息标记「待核实」。
- `00_Inbox` 是中转站，目标保持清空状态，不允许长期堆积。

## 二、检查

处理 `00_Inbox` 内容时，逐条回答五个问题，并给出 1～5 分：

1. **相关性**：是否与生成式推荐或推荐系统直接相关？偶发提及不算。
2. **新鲜度**：是否是新方法、新模型、新趋势、新数据集或新评测结论？
3. **价值度**：是否值得长期保存、引用或深入研究？
4. **可输出性**：能否变成文章、报告、综述或周报的一部分？
5. **关联性**：能否与已有知识卡片、选题或专题建立真实连接？

任一项低于 2 分的内容默认进入归档或忽略，不再重复处理。

## 三、分类

按检查结果打分后，执行五档决策：

| 决策 | 条件 | 去处 |
| --- | --- | --- |
| S 进选题池 | 高价值且可展开研究、写作 | `03_Topics/选题池` |
| A 做知识卡片 | 有可复用的概念、方法、案例 | `02_Knowledge` 对应子文件夹 |
| B 存参考资料 | 有价值但暂不加工 | `01_Sources` 对应子文件夹 |
| C 归档 | 已完成或暂时用不上 | `归档` |
| D 忽略 | 与方向无关、重复或低价值 | 不保存，或仅保留链接备查 |

知识卡片子文件夹用途：

- `概念卡片`：生成式推荐相关概念、范式、术语辨析。
- `方法卡片`：模型方法、训练策略、提示与检索策略、评测方法。
- `模型与案例`：具体模型、系统实现、产业落地案例。
- `工具卡片`：代码库、数据集、实验框架、效率工具。

卡片命名使用「主题 + 核心观点」，例如《生成式召回为什么适合冷启动场景》；新闻和日期类内容命名为 `YYYY-MM-DD｜内容提炼标题`。

标签规则沿用知识库标签索引：每篇 1～3 个主题标签，优先复用 `生成式推荐`、`推荐系统`、`AI` 等已有标签。

## 四、复盘

- **每周复盘**（建议每周日）：清空 `00_Inbox`，检查本周新增卡片与选题，把一周内值得跟进的问题写进 `03_Topics/问题清单`，复盘记录存 `05_Review/每周复盘`。
- **每月总结**（建议每月最后一个周日）：回顾本月输出成果与未完成选题，调整下月重点，记录存 `05_Review/月度总结`。
- **知识库优化**：发现标签重复、文件夹职责不清、卡片命名不统一时，记录到 `05_Review/知识库优化记录`，批量改动前先列影响范围并确认。
- 每日简报以 `01_Sources/论文报告` 或 `03_Topics/论文报告` 中轮换的一篇论文为底稿，解析其 References，筛选近 5 年且与生成式推荐相关的条目，生成简读后存 `05_Review/每日简报`；Horizon 的新闻摘要进入 `00_Inbox/自动抓取`，等待人工检查。

## 五、输出

| 输出类型 | 去处 | 说明 |
| --- | --- | --- |
| 文章、综述 | `04_Outputs/文章` | 从选题池或知识卡片组合成稿 |
| 报告、会议材料 | `04_Outputs/报告` | 面向课题汇报或行业分析 |
| 周报、月报 | `04_Outputs/周报总结` | 汇总一周输入、进展与产出 |

输出规则：

- 输出必须基于已核实的知识卡片和原始资料，标注来源链接。
- AI 生成的初稿放入 `04_Outputs` 对应子文件夹，文件名加 `｜初稿`，核对确认后去掉后缀成稿。
- 已发布或已交付的成品保留在 `04_Outputs`，写作过程稿放 `中间过程`，被替代的版本移入 `归档`。

## 六、文件夹总览

```
00_Inbox          信息入口（自动抓取 / 手动剪藏）
01_Sources        原始资料（论文 / 新闻 / 会议 / 旧资料）
02_Knowledge      知识卡片（概念 / 方法 / 模型案例 / 工具）
03_Topics         选题与研究（选题池 / 专题 / 问题清单）
04_Outputs        输出成果（文章 / 报告 / 周报）
05_Review         复盘迭代（每日 / 每周 / 每月 / 优化记录）
06_Skills         技能包（本规则文件所在处）
99_Attachments    附件素材（图片 / PDF / 表格 / 视频）
```

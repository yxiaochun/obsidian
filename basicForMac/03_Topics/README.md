## 维护规则

- 新选题先列出核心问题、可用卡片和证据缺口，再决定是否开专题。
- 能直接回答的问题转入知识卡片；暂时不能回答的问题保留在问题清单。
- 每周复盘时检查哪些问题已经被新论文或新卡片回答。
- 选题对应的候选输出和正式产出统一登记到 [[04_Outputs/README.md|输出索引]]；定稿后要把发现回流回知识卡片、选题或问题清单。

# OCPM计费一价改二价为何会被广告主感知

> [!info] 一句话结论
> OCPM 出价产品把计费从一价改成二价，广告主**会感知**：短期感知强烈（实际成本系统性低于出价、波动加大、平台收入下滑），长期因自动出价把成本推回目标而减弱，但通过报表和数据分析始终可以推断出计费规则变了。

## 背景：OCPM 的出价与计费结构

OCPM 中广告主出的是**目标转化成本**（bid_conv），平台折算成 eCPM 参与竞争：

$$bid\_ecpm = bid\_conv \times pCTR \times pCVR$$

计费方式直接决定广告主侧看到的"实际转化成本"：

| 维度 | 一价结算 | 二价结算 |
| --- | --- | --- |
| 扣费 eCPM | 自己的出价 eCPM | 下一名 eCPM（+微加价） |
| 实际转化成本 | ≈ 出价，恒定可控 | 下一名价格 / (pCTR × pCVR)，恒低于出价 |
| 成本波动 | 贴着自己 bid 走的直线 | 随竞争环境波动，方差大 |

## 短期感知：成本信号立刻变化

- 一价下"实际成本 vs 目标成本"的 gap **恒等于 0**；二价下 gap **持续为正且方差变大**。
- 切换当天，监控实际成本的广告主就能从日报看出异常，不需要精密实验。

## 中期感知：两类广告主的反应不同

**成熟广告主（自动出价/规则调价）**：PID 控制逻辑是"实际成本低于目标 → 加价抢量"。二价初期成本骤降会触发系统性加价，几轮迭代后成本回到目标附近。无论一价还是二价，重复博弈中目标成本型广告主的稳态都是"实际成本 = 目标"，所以这层的长期感知会减弱，但切换前后的成本轨迹会被记住。

**数据分析能力强的代理/大客户**：即使平台不公开计费规则，也能从数据反推：

- 把实际扣费对竞争强度（竞争广告数、行业出价分布）做回归——二价下扣费与**对手出价**强相关，一价下只与**自己出价**相关；
- "成本波动与竞争激烈程度正相关"这个模式也非常特征化。

## 机制设计层面的深层差异

即使广告主行为收敛到类似均衡，二价切换仍有可感知的副作用：

1. **成本归因被预测误差污染**。二价扣的是别人的 eCPM，但要除以自己的预估 pCTR × pCVR 才得到转化成本，预估偏差直接打进实际成本；一价扣的就是自己的出价，没有这个问题。
2. **波动性上升**。一价成本由自己控制，二价成本由对手决定，对做预算规划和 ROI 核算的广告主，方差本身就是负面体验。
3. **并没有真正获得 truthful 性**。GSP 不是 truthful 的，OCPM 场景下二价同样不诚实——实际成本低于出价会诱导加价，"出价 = 目标成本"不再是不动点。想获得激励相容需要 VCG 而非 GSP 排序下的二价。
4. **平台收入短期下滑**，头部广告主加价回填需要时间，中间有收入洼地；平台若通过操纵预估补收入，又会传导成广告主侧的成本异动，双方都在感知。

## 总结与实践启示

- 短期感知强烈 → 长期感知减弱 → 数据可推断性始终存在。
- 实践中很多平台做 OCPM 时**名义二价、实际"按出价封顶"的混合结算**，本质就是因为纯二价在目标成本型广告主面前既不稳定也不可控；计费规则改动带来的账面收益，大概率会在几个月内被广告主的调价反应吃掉大半。

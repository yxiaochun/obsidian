# LLM推理能力注入实时推荐的路径

## 切入点

LLM 的推理能力进不了毫秒级实时链路，但推荐确实需要演绎推理能力理解复杂意图。2025-2026 出现了几条不同路径。

## 研究问题

- 近线 LLM 合成指令 + 在线小模型执行（OxygenREC 快慢思考）的指令时效性如何维持？
- PRM 式过程监督与 LLM 蒸馏哪条路径迁移性更强？
- 多模态基础模型（LEMUR）是否是隐式推理能力的来源？

## 证据强度评估

总体强度：中低。已有证据能说明“推理能力可以通过近线、轻量验证或多模态表征间接进入实时链路”，但三条路径没有公开同台对比，还不能判断哪条更具通用迁移性。

| 结论 | 证据强度 | 判断 |
| --- | --- | --- |
| 近线 LLM 生成指令、在线小模型执行，可在 50～80ms 时延内进入电商推荐 | 原文明确支持 | 来自 [[OxygenREC：快慢思考让LLM推理进入电商推荐]] 的京东六场景 A/B 结果，但各场景指标口径不同。 |
| 轻量过程奖励模型可以对层级 SID 生成做逐步纠偏，并用推理计算换回一部分精度 | 原文明确支持 | 来自 [[PROMISE：过程奖励模型解锁推荐推理时扩展]] 的公开数据、工业离线和 7 天 A/B；其代价是总参数约 +15%、推理时延约 +10%。 |
| PRM、快慢思考和奖励引导是三种可区分的“推理能力注入”路径 | 多篇来源支持 | [[测试时扩展与过程奖励进入推荐系统]] 将多条工业论文汇总成范式谱系；可支持方向判断，不支持具体方案排序。 |
| 端到端多模态表征本身是“隐式推理能力”的来源 | AI 推断 | [[LEMUR：端到端多模态推荐替代两阶段表征]] 证明了多模态与推荐目标联合优化有线上收益，但未直接测量推理能力。 |
| 指令时效性、PRM 蒸馏迁移性和算力预算的横向关系 | 待验证 | 当前缺少同一平台、同一流量、同一业务目标的对比；Beauty 收益低于 Sports 也提示收益依赖数据分布。 |

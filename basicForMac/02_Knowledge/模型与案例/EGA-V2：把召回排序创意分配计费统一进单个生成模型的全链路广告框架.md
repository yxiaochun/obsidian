# EGA-V2：把召回排序创意分配计费统一进单个生成模型的全链路广告框架

## 筛选与速览

- **一句话速览**：EGA-V2（End-to-End Generative Advertising）是美团外卖广告团队（与 [[NGA：非自回归生成式拍卖用全局外部性兼顾效果与推理效率]] 同一作者班底）提出的全链路生成式广告框架——用 RQ-VAE 语义 token 化 + 多 token 预测在**单个生成模型**内统一用户兴趣建模、POI 推荐、创意选择、广告分配与计费，计费用可微事后遗憾最小化在 POI 层做近似 IC。离线对比 MCA 级联架构 RPM +16.5%、CTR-poi +8.8%，对比 OneRec 生成式基线 RPM +10.3%，且 IC 指标 Ψ=2.7% 为全场最低（GR 基线 8.4%）。
- **核心贡献3句话**：① 提出首个把广告全决策链（召回→排序→创意→分配→计费）收敛进单一生成模型的工业框架，端到端输出广告序、创意、位置与支付；② 「兴趣预训练 + 拍卖后训练」两阶段范式 + token 级 max 聚合出价 + POI 级解耦支付网络；③ 美团 LBS 平台 2 亿请求、200 万用户、近 1000 万广告数据离线验证，消融显示两阶段训练对 RPM 贡献最大（去掉后 -5.3%）、支付网络对 IC 贡献最大（换成 GSP 后 Ψ 2.7%→8.2%）。
- **与我们系列的关系**：这是混排演进的下一站——[[外卖搜索广告生成式混排一期：用自回归生成与DPO偏好对齐替代贪心混排]] 和 [[外卖列表广告生成式整体拍卖一期：用非自回归生成与RegretNet计费突破阶乘组合空间]] 都只在固定候选集上做混排，EGA-V2 把上游召回/精排也吞进来，是「分配与计费联合端到端」空白（见 [[广告混排方案对比：外部性建模、生成范式与计费机制的路线分化]]）的最激进回答。

## 核心问题

级联架构（recall → pre-rank → ranking → creative → auction）两个固有缺陷：① 上游截断封死下游上限——在召回/排序阶段被过滤的广告，即使最终分配中价值再高也无法恢复；② 决策逻辑分散在互不连通的模块中，无法全局最优。生成式推荐（Tiger、HSTU、OneRec）虽提供端到端方案，但都没有处理广告特有的显式出价、创意选择、广告位分配和计费规则。

## 方法要点

### 4.1 兴趣预训练

- **输入输出**：用户行为序列 $S_u=\{(e^{poi}_i, e^{img}_i)\}$（POI 特征嵌入 + 创意图像嵌入，B=256 条历史行为），目标为当前 PV 会话中实际曝光的高价值 item 序列（K=10）；
- **RQ-VAE token 化**：稠密嵌入编码为语义 token，每个 item 表示为 POI-creative 对 $(a^{poi}_i, a^{img}_i)$；每个 token 由 C 层 codebook 组成 $a_i=(a^1_i,...,a^C_i)$（实验 C=3，每层 W=1024）；论文以单层 POI/creative token 为主，层级扩展留作框架能力；
- **概率分解**：先生成 POI 再生成创意的两段式分解 $P(a^{poi}_{t+1}, a^{img}_{t+1}|S^u_{1:t}) = P(a^{poi}_{t+1}|S^u_{1:t})\cdot P(a^{img}_{t+1}|a^{poi}_{t+1},S^u_{1:t})$——创意是 POI 之下的细粒度生成层，创意选择不再是独立阶段；
- **encoder-decoder + MTP**：encoder（无位置编码）编码用户兴趣，decoder 自回归生成；借鉴 Multi-Token Prediction（DeepSeek-V3 同款思路）用 POI decoder 和 creative decoder 两个头共享 embedding 空间联合训练，loss = $L_{NTP} + L_{MTP}$（两个交叉熵）。

### 4.2 排列感知奖励模型

- 输入每个生成 token 拼接原始 item 嵌入 $h_i=[a_i;e^{poi}_i]$，过 self-attention 建模序列内依赖 $h^f = \text{SelfAttention}(h)$；
- 多任务塔分别输出 pctr/pcvr：$\hat{r}^{pctr} = \text{Tower}(\sum h^f)$，Tower = Sigmoid(MLP)；真实点击/转化 label 的 BCE 训练；
- RM 是平台目标的**灵活接口**——替换 reward 信号组合即可改变优化方向。

### 4.3 拍卖式偏好对齐（生成式分配 + 解耦计费）

- **token 级出价**：RQ-VAE 后 item 与 token 是多对多映射，item 级出价不再适用。借鉴 Google 的 token-level bidding 理论（WWW '24, Mechanism design for LLMs），token $a^j_i$ 的聚合出价取关联 item 出价的**最大值**：$b(a^j_i)=\max(b_1,...,b_{N_i})$，出价权重 $w(a^j_i)=[b(a^j_i)]^\alpha+\beta$——α 实时调节出价对分配的影响强度，β 动态平衡广告与自然的占比；
- **生成式分配**：按 $z(a^j_i)=\frac{w(a^j_i)\cdot e^{a^j_i}}{\sum_k w(a^{j,k})\cdot e^{a^{j,k}}}$ softmax 采样，beam search 生成 N_S=64 条候选序列，用 RM 逐条打分 $\hat{r}_j = R(S^{(j)})$，取 reward 最高的 $S^*$ 输出；
- **POI 级支付网络**：分配在 token 层、支付回到 item/POI 层（符合广告主预期）。支付网络输入 $S^*$ 的 item 表征、去自身出价画像 $B^-$、期望价值画像 $Z\odot\Theta$（分配概率 × RM 的排列感知 pCTR），输出支付率 $\hat{p}=\sigma(\text{MLP}(S^*;B^-;Z\odot\Theta))\in[0,1]^K$，支付 $p=\hat{p}\odot b$；sigmoid 结构保证 IR；自然 item 支付为零。

### 4.4 两阶段训练

1. **兴趣预训练**：真实曝光序列（含广告+自然）上优化 $L_{pre\text{-}train}=L_{NTP}+L_{MTP}$，学用户兴趣；
2. **拍卖后训练**（冻结预训练参数）：
   - RM 训练：真实反馈 label 的 BCE；
   - 生成式分配训练：**策略梯度 + VCG 式边际贡献奖励**——$r_{y_i} = \sum_{y_j\in S^*} b_j\hat{r}^{pctr}_j - \sum_{y_j\in S^*_{-i}} b_j\hat{r}^{pctr}_j$（含 item 的最优序列收入 − 去掉 item 的最优替代序列收入），$L_{PG}=-\frac{1}{|D|}\sum \sum r_{y_i}\log z_{y_i}$；
   - 支付网络优化：拉格朗日对偶解约束优化 $L_{Pay}=-\frac{1}{|D|}\sum(\sum p_i\hat{r}^{pctr}_i - \sum\lambda_i\widehat{rgt}_i - \frac{\rho}{2}\sum(\widehat{rgt}_i)^2)$，交替更新支付网络参数与乘子 $\lambda^{new}=\lambda^{old}+\rho\cdot\widehat{rgt}$；论文承认非凸、无全局最优保证，但经验上有效。

## 实验与消融

**主实验**（数字经脱敏变换，保留统计性质）：

| 模型 | RPM | CTR-poi | CTR-img | IC 指标 Ψ |
| --- | --- | --- | --- | --- |
| MCA（Tiger+HSTU+Peri-CR+**CGA**+CrossDQN） | 192.45（-16.5%） | 0.0558（-8.8%） | 0.0529（-9.3%） | 3.6% |
| GR（OneRec+Peri-CR+GSP） | 206.73（-10.3%） | 0.0582（-4.9%） | 0.0546（-6.3%） | 8.4% |
| **EGA-V2** | **230.41** | **0.0612** | **0.0583** | **2.7%** |

关键读法：MCA 基线的 auction 组件就是 CGA——EGA-V2 与 CGA 是间接同台；GR 基线（OneRec+GSP）RPM 排第二但 Ψ=8.4% 最差，直接印证「生成式推荐直接搬进广告，IC 是第一个崩掉的约束」；EGA-V2 的 Ψ=2.7% 全场最低但仍非零——**近似 IC 路线的量级**（对照 [[MIRT：用maximal-in-range结构换取精确DSIC的whole-feed生成式拍卖]] 的批评）。

**消融**（去掉单个组件）：

| 变体 | RPM | 结论 |
| --- | --- | --- |
| EGA-mtp（去 MTP，顺序独立预测 POI/creative） | -2.1% | POI 与创意联合建模有效 |
| EGA-end（去两阶段，单阶段端到端训练） | **-5.3%** | 两阶段训练对 RPM 贡献最大 |
| EGA-bid（max 聚合改平均） | -3.2%，Ψ 2.7%→4.1% | max 聚合同时影响分配效率与 IC |
| EGA-gsp（支付网络换 GSP） | -1.8%，**Ψ 2.7%→8.2%** | 支付网络是近似 IC 的唯一来源 |

**超参敏感性**：α 增大先显著提 RPM 后平台期，CTR-poi 随 α 单调下降（曝光向高出价广告转移）；β 增大自然占比上升、RPM 单调下降——α/β 是收入-体验权衡的直接旋钮。

**实现细节**：A100 80G，Adam lr=0.0024，batch 128；encoder/decoder 均 3 层，codebook C=3 层每层 1024；K=10 目标、B=256 历史；beam search N_S=64；支付/RM 的 MLP 隐层 128-32-10。

## 批判性分析

### 创新层次

| 层次 | 内容 | 评价 |
| --- | --- | --- |
| 原理创新 | 单模型统一广告全决策链 | 「行业首批」声称成立，方向意义大但风险集中 |
| 结构创新 | RQ-VAE token + POI→creative 两段分解 + MTP 联合训练 | 创意 token 化对动态广告素材的覆盖是未讨论的假设 |
| 训练策略创新 | 兴趣预训练 + 拍卖后训练；VCG 式边际贡献做 PG 奖励 | 消融证明两阶段贡献最大（-5.3%），可独立迁移 |
| 机制设计 | CGA 遗憾最小化支付网络搬到 POI 层 | 非本文原创；Ψ=2.7% 是近似 IC 的量级声明 |

### 与内部方案对照（最有价值的阅读视角）

- **演进位置**：同一团队轨迹是 NGA（混排层非自回归生成，CIKM '25）→ EGA-V2（全链路统一生成）。内部六篇还停留在「固定候选集上的混排」，EGA-V2 把召回和精排也生成化了——印证对比笔记的隐含前提：混排优化到头后，下一步只能往上游走。
- **PG 奖励的 VCG 化**：$r_{y_i}$ 的边际贡献形式与 [[MIRT：用maximal-in-range结构换取精确DSIC的whole-feed生成式拍卖]] 的 VCG 外部项同构——EGA-V2 在 reward shaping 层面已经在借用 VCG 结构，但只在 PG 奖励里用，支付网络仍是 RegretNet 式，两者未对齐。
- **验证缺口**：离线指标用 RM 预估值计算（非真实归因），且数字脱敏；全链路生成模型的线上耗时、广告主工具链兼容性（出价透明度、计费可解释）都是级联架构用模块化换来的隐性资产，论文未触及。
- **对照内部一线数据**：EGA-V2 离线 RPM +16.5%（vs MCA）远大于内部混排一期的线上 +0.96%~+3.22%——主要因为对比对象不同（MCA 全链路 vs 混排模块），不能直接换算，但说明上游截断的消除空间确实比混排层大一个量级。

### 落地可行性评估

- 数据：工业规模曝光序列（内部具备）；RQ-VAE 需覆盖全量 POI 与创意；
- 推理：单模型覆盖召回→计费，延迟压力远大于只做混排的生成模型（外卖搜索一期已 +9.7ms）；论文未给线上延迟数据；
- 复杂度：整体架构重构级（高），复现需 RQ-VAE、生成模型、RM、支付网络、两阶段训练全链路；评分 ⭐⭐（作为工程复刻），作为方向研究参考 ⭐⭐⭐⭐。

### 美团业务适配

这就是美团外卖广告团队的框架，适配问题反转为「我们能否复用其组件」：层级 token 化 + 创意联合生成可独立迁移到到餐/外卖的生成式混排（候选 token 化后外部性建模空间更大）；拍卖后训练范式可直接替换 [[外卖搜索广告生成式混排一期：用自回归生成与DPO偏好对齐替代贪心混排]] 的 DPO 阶段做对照实验；token 级 max 聚合出价的 α/β 旋钮与全站推广的 ecpm+k·pgmv 排序目标有直接的概念对应。全链路统一在到餐场景受限于候选规模与延迟预算，短期不建议。

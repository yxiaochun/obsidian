# 多场景统一生成式推荐的架构对比

## 切入点

多场景统一是 2025-2026 的大趋势，但各家方案差异很大：快手 OneMall 用场景统一训练+RL 管线，京东 OxygenREC 用场景指令化+快慢思考，字节 MDL 把场景做成 prompt token，美团 MTFM 走免对齐异构 token，Meta TAE 用基础模型+专家迁移。

## 研究问题

- 场景信息以指令、token 还是奖励形式注入，各自适用边界是什么？
- 负迁移何时出现、如何检测？

## 证据强度评估

总体强度：中。“多场景统一/跨场景数据扩展是趋势”有多篇工业论文支持；但“指令、token、奖励或基础模型加专家哪个更好”仍不能下结论，因为各家业务、场景定义、基线和实验口径都不同。

| 结论 | 证据强度 | 判断 |
| --- | --- | --- |
| 场景统一训练配合 RL/奖励映射可以在快手电商多场景获得正向收益 | 原文明确支持 | 来自 [[OneMall：快手电商多场景统一生成式推荐]]，覆盖商品卡、短视频、直播，但未披露各场景流量比例和实验周期。 |
| 场景指令化配合近线推理和在线执行可以跨多场景部署 | 原文明确支持 | 来自 [[OxygenREC：快慢思考让LLM推理进入电商推荐]]，京东报告了六场景结果和 50～80ms 时延，缺少负迁移检测细节。 |
| 场景和任务 token 化能改善多分布学习 | 原文明确支持 | [[MDL：场景与任务token化统一多分布学习]] 是抖音搜索一个月 A/B，收益幅度小，但方向明确。 |
| 异构 token 和免对齐设计适合跨域/多场景基础模型 | 原文明确支持 | [[MTFM：免对齐的多场景推荐基础模型]] 有离线 GAUC 和美团两场景 A/B，证据仍限于单篇工业场景。 |
| 基础模型 + 专家是超规模多 surface 的可行范式 | 原文明确支持 | [[TAE：基础模型加专家范式的超规模部署]] 有 Meta 大规模部署、A/B 和资源数据，但仅限 Meta 数据与表面。 |
| “场景信息统一进 token”是较强趋势 | 多篇来源支持 | MDL、MTFM、TAE 都使用 token/异构表示；OxygenREC 用指令，OneMall 用统一训练和奖励，说明趋势是统一建模，不必然是同一注入方式。 |
| 各路线的负迁移触发条件和检测指标 | 待验证 | 没有公开 head-to-head 比较，也没有统一的负迁移度量。 |

# 生成式推荐为何开始替代级联管线

## 传统级联的结构性问题

召回→粗排→精排→重排各阶段独立训练、目标不一致，上游只优化自己的召回率/精度，误差逐级传播；逐候选独立打分天然忽略候选间相互作用（广告场景的外部性）。

## 生成式替代的核心论据

- [[OneRec：统一召回与排序的端到端生成式推荐]]：首个在生产环境显著超越成熟级联系统的端到端生成模型。
- [[GenRank：大规模生成式排序的工业验证]]：关键归因——收益主要来自生成式架构本身，而非训练范式。这意味着架构层面的优势是本质的。
- 广告线全面跟进：[[UniROM：广告排序的端到端统一生成架构]]、[[GPR：广告推荐的统一生成式预训练范式]]、[[OneRanker：一个模型统一生成与排序]]、[[GR4AD：广告生成式推荐的架构训练推理联合设计]]。

## 代价与边界条件

- 推理成本与时延压力 → 需要 [[UGSep：用户侧计算复用降低大模型推理成本]]、动态 beam 等配套。
- 生成式架构容易丢弃传统交叉特征 → [[MTGR：保留交叉特征的工业级生成式推荐扩展]] 证明保留交叉特征才能 scaling 成功。
- 层级 SID 生成引入语义漂移 → [[PROMISE：过程奖励模型解锁推荐推理时扩展]]。

## 当前结论

2025-2026 的行业共识：统一生成是方向，但落地依赖语义 ID 质量、推理成本控制和训练目标对齐三个配套系统。

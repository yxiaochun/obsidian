# 混排影子价格的自适应路线与三层控制架构

> [!info] 证据边界
> 本笔记中各组件全部有独立证据（见关联卡片），但**三层组合架构、三个接口设计与 k 的光谱划分属于推断性综合**，未见到公开完整实现。推理链条标记为「已验证 / 推断」。

## 核心问题

混排的拉格朗日松弛范式（[[混排Re-Rank：影子出价把参与度约束转化为自然与广告流的统一排序货币]]，KDD '20）把收入-体验权衡折算成统一货币：影子价格 α。其原始形态中 α 是离线解出的全局常数，只能靠 A/B 线搜索更新——静态假设被流量非平稳和人群异质性双打破（美团闪购的分人群数据直接验证了后者：同样放宽广告，不同人群的自然订单损失差异巨大）。本选题关注：**α（以及排序公式里的融合汇率 k）应该由谁来管、在什么时间尺度上更新、与生成式模型如何分工**。

## 三个基础认知

**1. 影子价格的数学与经济学含义**：α = 最优目标值对约束门槛的边际敏感度，即「1 单位 engagement 值多少钱」。它是业务可直接调的旋钮（调节 C 即沿 Pareto 前沿滑动），也是天然的约束紧张度仪表盘（约束不 binding 时 α=0）。详见混排卡片。

**2. α 自动吸收系统性偏差，但吸收不了条件结构错误**（推断，推理较完整）：模型把所有 utility 系统性高估 2 倍，DMD 稳态下 α 补偿到 2 倍，决策不变——汇率是相对的。但「广告衰减在上下半分布异质」这类**非线性上下文依赖**没有任何标量乘子能吸收。因此「估准」的绝对校准弱敏感，条件结构正确性强敏感——这决定了感知层的建设方向。

**3. 逐请求 α 严格不存在，存在的是 α(状态)**：混合排的约束是聚合约束，逐请求更新真正的对象是约束消耗状态。「请求级更新算子必须便宜」是硬约束——DMD 一次向量运算可以，LLM 推理永远不行（频率上不可实现，不是算力问题）。

## α/k 的自适应光谱

四条路线操作的是**同一个对象的不同自由度和更新机制**：

| 路线 | k/α 的管理方式 | 粒度与节奏 | 代表 |
| --- | --- | --- | --- |
| 排序公式基线 | 人工标定常数 | 全局、无更新 | 各厂现状（ecpm + k·pgmv） |
| 决策规则可微化 | 端到端离线学习公式的融合系数（e^δ·ecpm + e^α·ctr + …） | 场景级、随重训更新 | [[点评到餐NeuralAuction实验：用序特征实现计费调控并量化激励兼容代价]]、[[美团到餐多位次NeuralAuction实验：逐坑位竞拍兼容多模版灵活位次]] |
| LLM Agent 调参 | Agent 读回流推理调 K/δ，Memory 积累响应认知 | 人群级、天级 | [[人群Agent加寻参Agent让混排影子价格从全局常数走向人群级自适应]] |
| 对偶在线化 | DMD/对偶控制器随约束消耗逐请求更新 | 状态级、请求级 | Balseiro 等 dual mirror descent（预算 pacing 工业成熟） |

**关键反证**：NeuralAuction 单位次版本的 hour-aware rankscore（softplus(hour embedding) 输出公式系数，即最小可行的「α 条件化于请求上下文」）离线无收益未上线——请求级异质性在离线开环数据里学不出来，因为**没有约束消耗反馈，模型感知不到「什么时候该收紧」**。这反向论证在线闭环的必要性，也解释了为什么各路线止步于离线学习或人群级调参。

**Agent 路线的天花板**：推理成本（分钟-小时级）、请求级反馈信号稀疏（归因需要人群×时段统计量）、探索无法逐请求（安全红线）、Memory 会爆炸。即 Agent 的自然粒度上限是「天级·人群级」，突破它必须换更新算子。

另有一条旁支：逐请求直接解原问题（绕开对偶），如 Avito PermR（ILP + 相邻交换修复，A/B 收入 +2% 且约束零违反，2026 preprint 仅读摘要），适合承载**非加性约束**（相关性分位下限等）——拉格朗日框架装不下的部分是它的生态位。

## 三层控制架构（推断性设计）

分层哲学：**表达力问题交给权重，守恒问题交给显式变量，语义归纳问题交给语言模型**。

| 层 | 工具 | 时间尺度 | 职责 |
| --- | --- | --- | --- |
| 感知与分配 | 生成式打分/重排模型 | 单次推理 | 条件效用估计（r_i, u_i + 不确定性）、排列外部性、列表生成 |
| 控制 | 在线对偶控制器（DMD） | 每请求更新 | α(t) 随约束消耗状态滑动，守恒保证 |
| 治理 | LLM Agent + Memory | 天/周级 | 人群结构发现、α 区间与步长标定、异常归因 |

三个接口是架构成立的关键：

1. **模型 → 控制器**：输出效用估计 + 置信度；控制器用实际回流残差驱动对偶更新；不确定性决定更新步长（不确定大则保守）。
2. **控制器 → 模型**：两种模式——α 作**乘子**（显式比较 r+αu，透明可审计）或 α 作**特征**（模型学响应，表达力强）。稳妥路径先乘子后特征，且**两者的背离本身就是漂移告警**。
3. **Agent → 两者**：定界（α 区间与初值+安全论证）、调控制器超参（步长/探索率/约束目标 C）、喂模型（人群标签特征/蒸馏）、归因（「是模型估错、还是约束该改、还是人群结构变了」——纯 DMD 系统里 α 涨了没人知道该怪谁，这是 Agent 的最大独立价值）。

## 感知层的三档递进（A/B/C）

- **A 独立点估计**：传统 MTL 逐条估 pECMV/pgmv——决策需要的反事实条件量在它的框架里没有对象。
- **B 条件效用估计**：估计「这条自然结果前面插了广告后 CTR 剩多少」——把效用估计从独立逐条推进到条件于上下文与排列。**相对纯收益，不牺牲控制权，无条件做**。
- **C 生成式策略**：α 与约束余量作输入直接生成列表，决策权交割给权重。买到的：列表级联合效用、响应异质性、支付可进模型（[[CGA：自回归生成式拍卖捕捉排列级外部性并解耦分配与支付]]）。押出的：α 失去读数含义、守恒从构造性降级为经验性、误差归属被污染、需要 α 的训练分布探索覆盖。**切 C 的前置条件：B 估计器做 shadow 校验的背离护栏跑通**。

**NeuralAuction 的定位**：不落在 A/B/C 轴上，是正交的「决策规则可微化」路线——感知 ~A.5（序特征工程承载上下文，其规划中的列表上下文 Evaluator 正是往 B 补课）、决策 B+（结构保留 + 目标对齐）、控制静态学习（k 学成场景常数）。其多位次版的 IC 反转结论（提价 10 倍时模型极端扣费 3.29 vs 公式 15.06）值得记住：**激励质量取决于对出价分布响应的合理性，而不取决于规则是否手写**——但经验性结论不可推导，换分布不保证，所以要配价格杠杆/最小扣费量化评估护栏。

## 与全站推广的连接

排序公式 ecpm + k·pgmv 中的 k 即成交影子价格，本选题的架构直接适用：

- **k 交给控制器**（佣金率 ≥ 目标 C 作约束，成交回流驱动 k 更新），k 变成有守恒保证的实时量而非超参；
- **佣金率做约束而非排序项**，「学什么」（pgmv 估计精度、排列外部性）与「守什么」（佣金率红线）分离；
- 超额佣金率的跨品类割裂问题，与闪购「统一 K/δ 被人群异质性打穿」同构——Agent 层的品类×人群划分是对分布割裂的显式回应，且响应面认知积累成 Memory 资产。
- 全站推广排序计费分离的机制背景见 [[全站推广为什么排序计费分离仍需激励兼容]]。

## 开放问题

1. α 探索覆盖：训练日志中 α 需要多大分布多样性，模型才能学到对 α 的响应？（C 模式的前置成本）
2. 背离监控：乘子模式与特征模式的 α 语义差异如何稳定度量？
3. 佣金率约束的可加性：佣金率是比率型目标（收入/成交），做对偶约束需要转成差分或比率形式，守恒性与商户端激励如何分析？
4. 多约束场景（体验 + 佣金 + 预算）的对偶向量维度与优先级仲裁。
5. 反馈回路：混排调 α → 出价端 bidding 响应 → 均衡移动（LinkedIn 卡片遗留问题），在三层架构里仍属治理层归因职责，具体机制未解。

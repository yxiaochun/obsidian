# UGR：面向异构电商推荐的统一生成式排序

## 论文信息

- 作者与机构：Zonghe Shao、Huabin Chen、Sitong Lu 等 10 人；Alibaba Group（淘宝首页「猜你喜欢」团队）。
- 年份与来源：2026-10-29，arXiv 预印本，[arXiv:2610.39426](https://arxiv.org/abs/2610.39426)。
- 领域：推荐系统、生成式排序、计算广告、拍卖机制。
- 本地底稿：学城解读笔记 [km.sankuai.com/collabpage/2795115891](https://km.sankuai.com/collabpage/2795115891)（AI 整理，公式按原文校对）。
- 与我的研究关联：直接对应全站推广的混竞排序场景——统一生成替代「单业务排序 + 跨业务混排」，去偏塔模式可迁移到历史投放策略塑形的曝光日志清洗，GSP 兼容性推导对排序计费分离架构有直接参考价值。

## 一句话创新点

UGR 把生成式排序从「截断单业务候选 + 事后 mixrank」推进到「全量请求级异构候选一次生成」，用训练期广告去偏塔剥离历史广告曝光效应、serving 期加性回灌当前广告价值，在不改动 GSP 分配计价规则的前提下实现多业务混排。

## 核心问题

电商首页一次请求要从约 1000 个异构候选（自然内容 + 广告 + 其他业务）中挑出有限几个商品摆上屏。现有生成式排序有两个缺口：

1. **候选集被截断且只排单业务**：生成列表再交给 mixrank 与其他业务混排，混排改位置、改上下文，导致「模型生成的列表」与「用户最终看到的列表」不一致，训练目标与 serving 目标错位。
2. **只模仿曝光序列**：从曝光日志学 next-token，但曝光本身是既有策略（含广告投放策略）筛出来的结果，点击/成交等真实反馈未被充分利用。

同时，生产系统跑 GSP 二价拍卖，排序分 = 推荐分 + 广告价值（加性组合），生成式排序不能破坏这个约定。

## 方法拆解

### 1. 统一生成：前缀条件化自回归

给定用户与请求上下文 $x$、全量异构候选集 $C$（$M\approx1000$），直接从 $C$ 自回归生成列表 $Y=(y_1,\dots,y_L)$：

$$p_\theta(Y\mid x,C)=\prod_{t=1}^{L}p_\theta(y_t\mid y_{<t},x,C),\quad y_t\in C_t(y_{<t})$$

每步只能从「尚未被选中」的合法候选 $C_t(y_{<t})$ 里取，前缀每步变化、条件随之变化。

### 2. 低秩候选注意力（工程核心）

把 $M$ 个候选 embedding 堆叠为 $E\in\mathbb{R}^{M\times D}$，先 RMSNorm，再沿候选轴做低秩投影（Linformer 思路）：

$$H=\mathrm{RMSNorm}(E),\quad Q=HW_Q,\ \bar{K}=P_K(HW_K),\ \bar{V}=P_V(HW_V)$$

$$A=\mathrm{softmax}\!\left(\frac{Q\bar{K}^{\top}}{\sqrt{d}}\right)\bar{V}$$

$P_K,P_V\in\mathbb{R}^{r\times M}$ 是沿候选轴的可学习投影，生产 $r=8$。复杂度从 $O(M^2d)$ 降到 $O(Mrd)$，对候选数线性。**$H_C$ 全请求只算一次，解码全程复用**——候选间交互一次算完，解码每步只更新「候选此刻合不合适」（$u_t$ 随前缀变化，$h_i$ 不变）。

### 3. 请求上下文编码器

用户属性、请求上下文、多时间尺度历史行为序列 → Masked Self-Attention 聚合 → 压成**单个**请求上下文 token $H_x$。压成一个 token 的目的是让请求级条件全请求只编码一次，解码每步只对单 token 做 cross-attention。生产配置：1 层 attention、256 维、8 头。

### 4. 自回归解码器与打分头

以近期会话 token 为起点，每选中一个候选就把它的上下文化表示 $h_y$ 追加进解码输入。每步：causal self-attention + cross-attention（$H_x$ 为 KV）+ FFN。打分用缩放余弦相似度（AdaCos 思路）：

$$z_{\theta,t}(i)=s_t\cdot\frac{u_t^{\top}h_i}{\lVert u_t\rVert_2\lVert h_i\rVert_2},\quad u_t=\mathrm{Proj}_{\theta,t}(d_t)$$

余弦把打分约束在 $[-1,1]$ 再由 $s_t$ 统一缩放，避免内积幅值随训练漂移，候选间可比性更好。

### 5. 训练期广告去偏塔

独立小塔 $g_\phi$，输入广告特征与历史 eCPM，输出每个解码位置上的广告专属 logit 调整量：

$$\delta_{\phi,t}(i)=\mathbb{I}_{\mathrm{ad}}(i)\left[g_\phi(a_i;p_t)+\gamma_t\right]$$

$p_t$ 是可学习位置偏置，MLP 权重跨位置共享；塔很小（单隐层、宽度 8），输出层与位置偏置**零初始化**，训练初期不改变生成器 logits。训练期 next-item 分布为：

$$p^{\mathrm{train}}_{\theta,\phi}(i\mid y_{<t},x,C)=\frac{\exp\left(z_{\theta,t}(i)+\delta_{\phi,t}(i)\right)}{\sum_{j\in C_t(y_{<t})}\exp\left(z_{\theta,t}(j)+\delta_{\phi,t}(j)\right)}$$

**设计动机**：历史曝光同时反映用户偏好和历史广告投放策略，直接拟合会把广告曝光效应烙进推荐分；serving 时再叠加当前 eCPM 等于**双重计入**。用塔把历史广告效应吸收掉，生成器 logit $z$ 就是干净的用户效用分。消融实证：去塔时 $z$ 与 eCPM 相关系数 $r=+0.195$，带塔训练后变为 $r=-0.313$。

### 6. 训练目标：NTP + WSFT + PermPO

| 目标 | 监督信号 | 作用 |
| --- | --- | --- |
| **NTP** | 曝光序列（含去偏塔调整） | 基线序列监督，所有曝光商品一律学习 |
| **WSFT** | item 级真实反馈（点击/停留/成交） | 按 $w(i)$ 给曝光商品 log-likelihood 加权 |
| **PermPO** | list 级排列偏好 | 用反馈 DCG 构造严格偏好对，DPO 式 sigmoid 损失 |

- **WSFT**：反馈分数 $w(i)=F_{\mathrm{IPV}}+2F_{\mathrm{CVR}}$（IPV=点击或停留超 3 秒，CVR=成交），直接求和不截断。零反馈商品 WSFT 项为 0 但 NTP 保底。
- **PermPO**：取同请求曝光集合 $B$，用 $\mathrm{DCG}(Y)=\sum_t \mathrm{Gain}(y_t)/\log_2(t+1)$ 定义严格偏好对 $\mathcal{P}(B)=\{(Y^+,Y^-):\mathrm{DCG}(Y^+)>\mathrm{DCG}(Y^-)\}$，损失为 $-\log\sigma(\hat{s}_\theta(Y^+)-\hat{s}_\theta(Y^-))$。**关键细节：序列分只回传生成器 logits（不含塔调整 $\delta$）**，偏好监督直接打在 serving 路径上。
- **总损失**：$\mathcal{L}=\mathcal{L}_{\mathrm{NTP}}+\lambda_{\mathrm{WSFT}}\mathcal{L}_{\mathrm{WSFT}}+\lambda_{\mathrm{PermPO}}\mathcal{L}_{\mathrm{PermPO}}$，线上 $\lambda_{\mathrm{WSFT}}=1$、$\lambda_{\mathrm{PermPO}}=15$——list 级偏好监督权重是 item 级的 15 倍。

### 7. 在线 Serving 与 GSP 兼容

三步：

1. **广告价值融合**：$S_t(i)=z_{\theta,t}(i)+\alpha\,\mathrm{eCPM}_i$，$\mathrm{eCPM}_i=q_ib_i$，非广告为 0。
2. **多值序列检索**：束搜索式扩展前缀，路径累计分 $R(y_{<t}\oplus i)=R(y_{<t})+S_t(i)$，保留 top-$N$ 路径。生产 $N=4$、$L=4$。
3. **下游 evaluator 选终稿**：沿用现有下游 evaluator 从 $N$ 个列表里挑最终曝光列表。

**GSP 关键出价闭合形式**：前缀固定时，$i$ 的最高竞争分 $S^*_{-i,t}=\max_{j\neq i}S_t(j)$，广告 $i$ 赢下当前解码步的关键出价：

$$b^*_{i,t}=\frac{S^*_{-i,t}-z_{\theta,t}(i)}{\alpha q_i},\quad \alpha>0,\ q_i>0$$

分配规则、计价规则都不用改，广告侧机制无感接入。

### 8. 生产配置汇总

| 配置项 | 取值 |
| --- | --- |
| Token 表示维度 | 256 |
| 请求编码器注意力层数 | 1（8 heads） |
| 候选 embedding MLP | 512 → 256 |
| 候选注意力块 / 低秩 rank | 1 块 / $r=8$ |
| 候选 FFN / 解码器 FFN | 256 → 256（各两层） |
| 去偏塔 | 单隐层宽度 8，输出层与位置偏置零初始化，仅训练期使用 |
| 激活 / 归一化 | LeakyReLU / RMSNorm（$\epsilon=10^{-8}$） |
| 优化器 / batch / 学习率 | AdagradDecayV2 / 128 / 0.001 线性预热至 0.01（前 $10^6$ 步） |
| 损失权重 | $\lambda_{\mathrm{NTP}}=1$、$\lambda_{\mathrm{WSFT}}=1$、$\lambda_{\mathrm{PermPO}}=15$ |
| Serving：$M/N/L$ | 1000 / 4 / 4 |

整个模型非常克制——1 层 encoder、1 个低秩注意力块、塔宽 8、列表仅 4 个商品，赢在架构与监督信号设计而非堆参数，这解释了延迟增量只有 12ms。

## 实验证据

数据集：淘宝首页「猜你喜欢」30 天日志，按请求时间切分，候选集不截断不采样。场景 1：5468 万用户 / 1.18 亿商品 / 19.4 亿请求；场景 2：2415 万用户 / 9807 万商品 / 2.38 亿请求。

- **离线对比（6 基线：PRM / NAR4Rec / GReF / Dual-Rerank / UniRank / DEGR）**：两个场景下 UGR 在全部 6 个反馈类排序指标（IPV 与 CVR 的 NDCG、MAP、AUC）均为最优。场景 1：IPV NDCG 比最强基线 +4.86%（vs UniRank），IPV MAP +7.53%（vs DEGR），CVR MAP +2.05%（vs DEGR）。
- **Hitrate 与反馈质量分离**：UniRank 的 Hitrate（与曝光列表重合度）最高但反馈排序质量最差；UGR 的 Hitrate 仅中游（0.5295，与 PRM 持平），反馈类指标全列第一。**贴近历史曝光 ≠ 排得更符合用户偏好**。
- **线上 A/B（≥5% 流量，≥14 天）**：Core IPV +1.76%、交易量 +3.29%、GMV +2.10%（$p<0.05$）；广告护栏 Ad Cost +0.08%、Ad PVR -0.93% 均满足要求；平均推理延迟仅 +12ms。交易类收益明显大于点击类，说明 PermPO 的反馈 DCG 监督（成交权重 ×2）把交易价值排到了更靠前位置。
- **统一生成 vs 分阶段混排**：UGR-Single+Mix（限定只排自然内容，再由既有 mixrank 混排）也能带来 Core IPV +1.13%、交易量 +2.84%、GMV +1.38%，但完整 UGR 全面显著优于它——证明把跨业务混排和排序决策放进同一次生成里更好，混排改变位置与上下文造成的损失真实存在。
- **消融**：去 PermPO 时 6 个排序指标全部明显下降（IPV NDCG 从 0.3666 掉到 0.3453，几乎退回 NTP-only）；去 WSFT 时 NDCG/MAP 下降、AUC 略升；NTP-only 明显最差——三者互补，PermPO 贡献最大。去偏塔消融：去塔后 $z$ 与 eCPM 正相关（$r=0.195$），带塔后变负相关（$r=-0.313$），塔调整本身与 eCPM 强正相关（$r=0.727$）。候选截断：只保留 top-10/20 自然候选显著掉点；全量与 $K=30\sim200$ 截断差距小于 0.5%。

## 批判性分析

### 去偏塔的 serving 真实行为（笔记作者批注，最值得较真）

> 笔记原文批注：*个人倾向实际线上也用了去偏塔且没改广告计费，但是被挑战了激励兼容和广告计费问题，在论文里编了一个使用 ECPM 代替去偏塔，然后计算 GSP 的故事。*

如果这个判断成立，论文的 GSP 叙事就是事后自圆其说：

- serving 期若真用塔，$\delta$ 与出价无关，相当于给特定广告加固定偏置。虽然单调性（出价高 → $S$ 高）还成立，但 $\delta$ 与 eCPM 强相关（$r=0.727$）意味着 serving 期同时存在「塔里的历史 eCPM 效应」和「加性的当前 eCPM」，**双重计入**——这正是论文声称要消除的问题。
- 闭合形式 $b^*_{i,t}=(S^*_{-i,t}-z)/(\alpha q_i)$ 只在「serving 期确实摘塔」的前提下有效。
- $r=-0.313$ 是过度矫正：带塔训练后生成器对高 eCPM 候选整体打分偏低，说明塔可能吸走了部分真实偏好。Ad PVR -0.93% 说明广告转化确实受损。

### 其他疑点

- **低秩 rank=8 的瓶颈**：论文没做 full attention 对照。截断实验侧面说明收益主要来自「不截断」，但 $P_K,P_V$ 是输入无关的固定投影，对「广告 vs 自然」这类角色差异大的场景可能不够灵活。
- **PermPO 的适用范围**：偏好对只在曝光集合 $B$ 内部构造，隐含假设「曝光集合本身没问题，只是顺序不对」。若曝光集合漏了高反馈候选，PermPO 学不到。且 $L=4$ 是枚举可行（$4!=24$）的前提，$L$ 增大则排列枚举爆炸，PermPO 适用性与列表长度强耦合。
- **WSFT 的本质**：仍是对 NTP 的 log-likelihood 加权，没有显式负样本，零反馈商品仍被 NTP 保底学习。它提升 NDCG/MAP 但不提升 AUC（消融中 AUC 略升），符合「加权不改变排序对」的直觉。
- **GSP 推导的边界**：$b^*_{i,t}$ 是单候选视角，假设其余候选的 $S$ 不随 $i$ 的出价变化。实际 GSP 中同一广告主可能有多个候选，提高一个候选的出价可能挤出自己的另一个候选，这个外部性未建模。
- **α 的取值**：笔记未给出广告价值融合权重 $\alpha$ 的具体值，它直接决定广告价值在排序中的话语权，是线上最敏感的旋钮。

### 优点

- 把 train/serve discrepancy 从「概念批评」变成「可对照实验」：UGR-Single+Mix 与完整 UGR 的对比干净地量化了混排损失。
- 去偏塔模式通用性强：任何「历史日志被策略塑形」的场景（广告、运营干预）都能用类似结构去偏，避免线上价值被双重计入。
- PermPO 只回传生成器 logits（不含塔）这个细节很巧妙，保证偏好优化直接作用在线上打分路径上。
- 实验设计严谨：Hitrate 与反馈排序质量的分离、去偏塔的相关性分析，都是可复用的论证范式。
- 模型克制（1 层 encoder、1 个低秩块、塔宽 8），工程落地性好，延迟增量仅 12ms。

### 不足

- 论文真实性已验证（arXiv:2610.39426 存在，摘要与笔记一致），但笔记为 AI 整理，公式与符号虽按原文校对，细节仍建议对照原文。
- 单篇工业论文、单平台（淘宝首页）、14 天 A/B，缺少开源代码、公开数据和更长周期验证。
- 去偏塔的 serving 行为、rank=8 的精度瓶颈、PermPO 的集合外泛化，三个问题都需要进一步验证。

## 值得追踪的引用

- HSTU（Zhai et al., 2024）：生成式排序的缩放路径参照，UGR 的架构基础。
- PRM / NAR4Rec / GReF / Dual-Rerank / UniRank / DEGR：UGR 的 6 个离线基线，代表 list-wise 生成式排序的现有水平。
- Rerank-DPO：PermPO 的 DPO 式损失直接参考相对列表偏好优化方向。
- Linformer（Wang et al., 2020）：低秩候选注意力的投影思路来源。
- AdaCos：缩放余弦相似度打分头的设计来源。

## 复现清单

- **数据**：淘宝首页「猜你喜欢」30 天日志构造的两个工业数据集，不公开。场景 1 约 19.4 亿请求，场景 2 约 2.38 亿请求。
- **代码**：论文未提供开源仓库或实现链接。
- **关键配置**：token 256 维；encoder 1 层 8 头；候选 MLP 512→256；低秩 rank $r=8$；FFN 256→256 各两层；去偏塔单隐层宽 8、零初始化；LeakyReLU + RMSNorm；AdagradDecayV2、batch 128、lr 0.001 预热至 0.01；损失权重 1/1/15；serving $M=1000$、$N=4$、$L=4$。
- **缺失信息**：$\alpha$ 取值、去偏塔输入特征完整列表、PermPO 偏好对构造的采样策略、下游 evaluator 的具体形式。
- **改良设想**：把 PermPO 偏好对从曝光集合扩展到全量候选（用反馈模型给未曝光候选打分）；对低秩注意力做 full attention 对照；对去偏塔做 serving 期行为验证（是否真摘塔）；把列表长度 $L$ 增大时用 list-wise DPO 或采样近似替代枚举。

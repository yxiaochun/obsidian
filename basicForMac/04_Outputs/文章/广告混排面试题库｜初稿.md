# 广告混排面试题库｜初稿

> [!info] 使用说明
> 本题库基于个人美团广告混排相关笔记整理，答题要点全部以各篇笔记原文数据为底，供面试前自查。第 6、8、12 题涉及 MIRT 与 GRPO 的部分是笔记中的个人推断，面试时应表述为「基于文献的判断」而非既成事实。

## 一、项目叙事层（开场必问）

### 1. 用 3~5 分钟介绍你负责的广告混排工作，讲清楚演进主线

要点：

- 主线讲三轴：外部性建模从集合级 → 排列级 → 整页级；生成范式从 rankscore 可微排序 → 自回归 → 非自回归；计费从 NeuralAuction 调控 → RegretNet 遗憾最小化。
- 各期数字：点评到餐 NA（RPS +1.99% 置信、ROI +1.73%）→ gDNA（RPS +3.44%、CTR +2.46%、耗时反降 10ms）→ 外卖搜索（收入 +0.96%、耗时 +9.7ms）→ 外卖列表（收入 +3.22%、CPM +4.29%、IC 指标 -30%）。
- 叙事落点：瓶颈从「生成侧组合空间」转移到「评估器/校准」，再暴露到「计费与 IC」。

### 2. 你们怎么归因收益来源——是真分配更优，还是变相扩量？

要点：

- 最强证据是外卖搜索一期的对照实验：单纯降 CPM 阈值扩曝光 +1.46% 只换来收入 +0.17%、CTR -1.20%，而生成式混排同等曝光增幅下收入 +0.96%。
- 外卖列表：曝光 -1.03% 下收入 +3.22%，纯效率驱动。
- gDNA：位次分段分析，平均曝光位次 30→33 整体后移、前 10 位曝光减少、大部分位次 CTR 好于或持平基线，排除「位置红利」解释。

## 二、机制设计深挖层

### 3. NeuralAuction 是怎么做计费调控的？为什么要用「不含原始 bid 的序特征」？

要点：

- 原理：set encoder 的 embedding 压缩 rankscore 密度，GSP 二价下相邻 rankscore 越接近计费越趋近一价，实现二价到一价的连续调控。
- 特征阶梯消融：基础特征计价比只 0.72% → +bid 序特征跳到 4.83% → 含原始 bid 到 6.58% 但破坏价格杠杆与最小扣费，主动放弃，属于「效果换机制稳定性」的取舍。
- 无效提价损耗：离线不做截断的计价比虚高 15.19%。

### 4. 你们的机制对激励兼容付了多少代价？怎么量化的？

要点：

- 自建价格杠杆（α×Bid 扰动看曝光响应）与最小扣费指标。
- 含原始 bid 的特征是 IC 主要破坏源；set encoder 显式聚合会让候选间共享 bid 上下文、破坏 IC——所以最终选无聚合结构，即使 attention pooling RPS 略高。

### 5. 外卖列表为什么把 AMA 计费换成 RegretNet？RegretNet 怎么训？

要点：

- 基线两个 IC 缺陷：top4 用 AMA、非 top4 用 GSP，同一序列计费模式不一致；耗时截断导致组合空间不完整。
- RegretNet：生成器冻结后用增广拉格朗日最小化事后后悔，支付网络 sigmoid 输出计费率、结构保证 IR。
- 结果：IC 指标离线 -30%，价格杠杆线上扰动差值仅 +0.48%。

### 6. 近似 IC 的风险到底多大？（追问前沿）

要点：

- 引 MIRT 的批评：regret 惩罚式方法的误报收益可达广告主效用 10% 量级，且调大 ρ 压 regret 会牺牲福利——「价格杠杆持平」只是乐观下限声明。
- 结构保证（MIR+VCG）可做到精确 DSIC，但代价是 VCG transfer 的广告主接受度；「何时选精确 DSIC」取决于延迟预算、结算方式和误报容忍度。

## 三、生成范式选型层

### 7. 为什么外卖搜索用自回归 + DPO，外卖列表却用非自回归 + 策略梯度？

要点：

- 三个场景参数决定：浮动位数量（列表 20 个浮动位是阶乘空间，自回归算不动）、性能预算（搜索 +9.7ms 已接近极限）、机制成熟度（列表有 AMA 基础才能直接跳 RegretNet）。
- 自回归能同时感知集合外部性和准确的前序排列外部性，NAR 用约束解码 + Listwise 评估器换效率。

### 8. DPO 和 GRPO 怎么选？（大概率被追问到二期规划）

要点：

- 判据一个维度：标量 reward 是否可信。搜索的 listReward 依赖校准 ctr、绝对值漂移 → DPO 的相对偏好对全局尺度偏差免疫；列表评估器已被价格杠杆实验验证 → GRPO 严格更优。
- 深一层：DPO 只用日志中的曝光 pair，曝光偏差锁死探索空间；GRPO 的组内标准化还顺带解决跨请求 reward 尺度问题。
- 两个纪律：KL 锚防评估器被组内相对优化放大偏差；每次迭代后需重训计费（两阶段顺序不能破坏）。

### 9. 生成模型怎么保证离线学习和线上卡控一致？

要点：

- mask 约束矩阵刻画线上广告约束（最大起始位置/最大连续广告数/总数），随已决策序列动态更新。
- 自然保序的结构设计：分配矩阵第 n+1 列放自然 score，采样只会取到当前排序最靠前的自然 item，不需要显式对齐。
- 首位求交逻辑不受影响——实验里首位持平是符合预期而非异常。

## 四、评估与实验设计层

### 10. 混排线上实验你会报哪些指标？哪些是别人容易漏的？

要点：

- 通用：收入/RPM/CPM/CTR/CVR/ROI/曝光/RT。
- 三个容易漏的：① 曝光通道必须报，否则扩量冒充分配效率；② 自然侧体验指标（多数方案是盲区，k·imp 惩罚系数敏感性未展开）；③ 价格杠杆扰动验证（α∈{0.2..2.0} 十档，看曝光响应曲线是否与基线重合）。

### 11. IC 离线仿真怎么设计？Ψ 指标什么口径？

要点：

- 定义：相对事后遗憾 = 误报最大效用增量 / 真实效用，出价做 α×Bid 十档双向扰动。
- 口径警告：不同方案 Ψ 的分母不同（CGA 预设分布、EGA-V2 用预估 reward），数字接近但不可比；经验 regret 估计本身可能测不出某些误报方向。

## 五、开放与前沿层

### 12. 如果让你做下一代方案，路线是什么？

要点：

- 近期：GRPO 组内优化 + 评估器升级（用户行为序列 + Semantic ID，评估器准度比生成器杠杆更高）。
- 中期：分配与计费联合端到端的受控实验（目前 RegretNet 必须冻结生成器，两阶段目标一致性未验证）；自然体验从 k·imp 惩罚升级为对偶控制（人群级影子价格实验：收入 +1.83% 订单持平，说明扶持力度的体验成本因人群而异）。
- 长期：全链路生成（EGA-V2 离线 RPM +16.5% vs 混排一期的 +0.96%~+3.22%，说明上游截断消除的空间大一个量级），但延迟、回滚、失败归因前置。

### 13. 你们的工作和 CGA（淘宝）什么关系？数字可比吗？

要点：

- 关系：搜索一期 ≈ CGA 的工业化版本（自回归 + 评估器 reward）；列表一期的 RegretNet 与 CGA 的 PaymentNet 同属遗憾最小化阵营。
- 不可比的理由要主动说：流量比例、实验周期、出价参数、结算方式、基线全部不同；「多篇来源支持的趋势」和「跨场景排行榜」是两回事。

## 六、评估器升级深挖（第 8、12 题的追问准备）

### 14. 为什么评估器升级排在生成器升级之前？（先讲证据链）

- [[外卖列表广告生成式整体拍卖一期：用非自回归生成与RegretNet计费突破阶乘组合空间]]：生成器 reward 完全由 Listwise 评估器的 listctr 组装，单序列 PG 意味着评估器噪声 1:1 进入梯度方向。
- [[外卖搜索广告生成式混排一期：用自回归生成与DPO偏好对齐替代贪心混排]]：listReward 依赖校准 ctr、绝对值漂移，被迫选 DPO 这种「对 reward 尺度免疫的降级方案」——评估器不准直接改变范式选型。
- [[美团到餐gDNA一期实验：把自然候选当作零出价广告的整体拍卖混排]]：广告/自然预估分 diff 太大（CVR 归因口径差 2 倍），listwise 校准训练不稳定，整个退化为 posBias 乘法。
- [[外卖搜索广告校准模型的LLM文本建模：双路transformer与三重loss对齐文本与ID表征]]：不动生成器、只升级校准模型表征，AUC +0.5pp 换来线上收入 +1.04%（且做了缩曝光对照证明是排序收益而非扩量）——评估器准度的杠杆被单独实验验证。
- [[CGA：自回归生成式拍卖捕捉排列级外部性并解耦分配与支付]]：外部性建模 point→set→permutation，CTR AUC 0.7366→0.7391→0.7476 单调提升，且 Evaluator 是明确可替换组件。
- 反面教训：[[UniROM：广告排序的端到端统一生成架构]] 让 AucFormer 兼任离线 replay 评估器，eCTR/eRPM 离线收益被内部评估假设污染——评估器不准还会污染实验结论本身。

工程杠杆：外卖列表是 G-E 架构，线上只部署生成器 + 计费，评估器留在离线训练侧——升级评估器几乎不占线上延迟预算，而生成器升级（自回归 +9.7ms）是拿真实延迟换的。

### 15. 评估器升级的四层方案

**L1 表征层——看得更多（风险最低，先做）**

- 用户行为序列引入（外卖列表原文明确的下一步）：从纯数值/类别特征扩展到用户侧序列信号，评估器才能回答「这个排列对这个用户的外部性」。
- Semantic ID（LLM 校准原文明确的下一步）：连续文本表征量化为离散 token，与 ID 特征获得一致学习范式；参考 TRM 的 gen/mem 双 token 结构（gen 管泛化、mem 管记忆）与 GR4AD 的业务感知编码；对生成器同样关键——token 化后表达空间从打分排序扩展到 EGA-V2 式 token 生成。
- LLM 文本表征（已落地）：双路 transformer + 三重 loss 的设计决策可迁移，尤其 stop-gradient 单向对齐——只让文本向 ID 靠拢、不反向，因为 ID 侧有精排 pCTR 强特征且收敛快，反向会拉偏 ID 表征。
- 机制侧特征（MIRT 启发）：评估器应增加自然侧效用估计头（自然 CTR/参与率），让自然体验从 $k \cdot imp$ 线性惩罚补丁变成可学习的排列级估计。

**L2 结构层——外部性建模更准**

- 排列级校准加深：对照 CGA 的 Generator-Evaluator 结构补「完整序列校准」（生成器只看前序、评估器看全排列）。
- 多任务扩容：现有 $L_E = L_{ctr} + \alpha L_{imp}$ 可扩展 pCVR、自然参与率多塔，与混排 reward 的多目标结构对齐。
- 保留已验证的信息增强技巧：pCtr 多精度离散化 → 残差注入（外卖列表现成模式）。
- 独立校准源：吸取 UniROM 教训，评估器不兼任 replay 评估，离线收益用独立校准模型或线上真实反馈交叉验证。

**L3 目标与训练层——解决「准在哪个分布上」**

- 归因口径对齐（gDNA 根因）：广告/自然归因口径差 2 倍 CVR，长期方案是 label 口径统一 + 统一模型训练，短期只能在特征层绕。
- 反事实校准：评估器只在真实曝光分布上准，对生成器要探索的未曝光排列未必准；用价格杠杆扰动流量、多路小流量探索数据做分布外校准。
- reward 尺度稳定：后验曝光加权（搜索已做）+ 跨请求组内标准化（GRPO 顺带解决），避免请求间 bid/pCvr 尺度差异导致漂移。
- 更新节奏纪律：评估器先收敛 → 冻结 → 训生成器 → 训计费；引入 GRPO 后生成器分布漂移，评估器定期重训 + 生成器加 KL 锚（对显式分数先验 $A_{t,j}=M_{tj}+bid_j \cdot ctr_j+cvrk \cdot ctr_j \cdot cvr_j$），防 reward hacking 被组内相对优化放大。

**L4 验证层——证明「更准」而不只是 AUC 好看**

1. 离线常规：AUC/logloss、分位次 pcoc 校准曲线、按位次分段的 CTR 校准误差。
2. 机制级干预验证：α×Bid 十档扰动下的曝光响应——评估器对外生价格变化的预测是否与真实曝光一致。
3. 缩曝光反证（LLM 校准的关键手法）：曝光 -0.44% 下收入仍 +0.61%，证明收益来自排序质量而非扩量；评估器升级实验复用该归因协议。
4. 扰动序列一致性：对生成器采样的未曝光序列，评估器打分 vs 小流量真实反馈的一致性——GRPO 启动前的 go/no-go 检查。

### 16. 优先级与依赖关系（和 GRPO 选型的闭环）

```
L1 表征（行为序列 + SID，各自独立 A/B，风险低）
   ↓ 评估器准度达基线后
L2/L3（排列级结构 + 反事实校准 + 归因对齐）
   ↓ 通过 L4 一致性测试后
GRPO 组内优化（依赖可信的标量 reward）
```

逻辑闭环：GRPO 选型判据是「reward 是否可信」，评估器升级就是把 reward 从不可信做到可信的前置工程——两条线是同一项目的两个阶段，不是并列选项。

### 17. 一分钟话术

> 「我们复盘几期混排实验后发现，生成器升级的边际收益开始被评估器准度卡住：外卖列表的 reward 完全依赖 Listwise 评估器，搜索一期因为校准 ctr 漂移被迫选 DPO，gDNA 因为归因口径不一致直接放弃了 listwise 校准。所以二期的第一优先级是评估器而非生成器：近期引入用户行为序列和 Semantic ID 增强表征——LLM 文本校准已经单独验证了这条路径，AUC +0.5pp 换来收入 +1.04%；中期解决两个更深的问题，一是反事实校准，让评估器在生成器要探索的未曝光排列上也准，二是广告/自然归因口径统一。并且它还有个工程优势：列表场景评估器只在离线用，升级它不占线上延迟，而生成器升级要拿 +9.7ms 换。评估器可信之后，GRPO 的标量 reward 选型判据才成立，组内优化才能安全启动。」

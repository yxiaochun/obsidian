# 人群Agent加寻参Agent让混排影子价格从全局常数走向人群级自适应

> [!info] 证据边界
> 本卡片依据美团内部学城推全申请文档整理（AI 阅读，2026-10-19）。所有效果数字为文档自报口径，未经独立核验；推全申请文档通常只呈现成功结论，失败过程与迭代细节可能被省略。

## 项目信息

美团闪购「推荐商家流 Agent 驱动混排探索一期——参数自动寻优」（2026-08-05 至 08-19 线上观察，闪购频道页商家流 slot 9/12/15/66/72）。这是对 LinkedIn 混排范式（[[混排Re-Rank：影子出价把参与度约束转化为自然与广告流的统一排序货币]]）中「对偶参数全局常数」局限的一次工业演进：把影子价格从离线解出的单点常数，变成人群级、可自动迭代的参数。

## 核心问题

闪购商家流混排沿用「收入最大化 + 体验约束」的拉格朗日松弛形式：

$$
\text{广告得分} = ctr\cdot bid - \delta + K\cdot ctr\cdot cvr,\qquad
\text{自然得分} = K\cdot ctr\cdot cvr.
$$

K 是转化的影子价格，δ 是广告的密度税，二者共同决定体验成本的折算标准，原方案中均为全局常数。局限在于：广告占位的真实体验成本取决于用户浏览意愿与广告耐受度，具有强人群异质性。统一折算标准下，真实成本被高估的人群有效广告被过度过滤（丢收入），被低估的人群低效广告被放出（伤体验），两类浪费同时存在。

此前差异化调参受限于两个能力缺口：一是传统新老客、活跃度等聚合标签与「广告耐受度」相关性弱，缺乏对齐体验成本物理含义的人群刻画；二是 K/δ 只能人工试错，缺乏反馈闭环。

## 方案要点

三模块多 Agent 系统，形成「识别 → 执行 → 反馈 → 再决策」闭环：

- **人群 Agent**：用 opus 模型分析抽样用户的完整浏览-点击-转化序列，从轨迹归纳浏览意图与广告容忍度，输出可解释的人群划分 SOP 及初始调参建议；再用轻量 qwen 按 SOP 对全量活跃用户打标（蒸馏准确率 80%+），产出 uuid 在线特征，天级更新。未打标或置信度不足的用户回退全局默认参数。
- **人群 Memory**：持续回收各人群在线表现——人群分布趋势、历史 K/δ → 收入/体验的响应、其他指标响应、每轮策略决策日志——作为寻参 Agent 的核心决策输入，保证调参认知跨轮次积累。
- **混排 Agent**：离线触发，两阶段对人群级 K/δ 寻参：边界探测（大步长试探响应边界，定位有效参数区间）+ 收敛优化（已知边界内小步长微调）。两阶段均受全局约束：收入提升、体验持平于 baseline。输出各人群差异化策略，替换在线混排参数。

Agent 全部作用于离线链路，在线只读人群标识与调整系数，线上性能零增量。

## 线上效果与收益来源

30% 流量、连续 15 天（2026-08-05 ~ 08-19）：收入 +1.83%、广告曝光 +2.03%、CTR +0.34%、CVR +0.11%、ROI +0.79%、CPM −0.19%、总订单基本持平（+0.02%）。收益来源是订单大盘稳定前提下的**曝光结构迁移**：自然曝光向广告曝光迁移（自然曝光 −0.51%），两类曝光转化效率相当，广告曝光增量在 CPM 持平下直接转化为收入。

分人群结果（日均 Diff）验证了「体验成本人群异质性」前提：

| 人群 | 用户特征 | 寻参意图 | 收入 Diff | 总订单 Diff | 机制解读 |
| --- | --- | --- | --- | --- | --- |
| 广告易转化 | 广告当购物入口，广告转化强于自然 | 多放广告（K/δ 同向叠加） | +2257 | +299 | 本次收入主来源，收入体验双正 |
| 双高均衡 | 广告自然都活跃，广告挤自然 | δ 不动只调 K，多给自然 | +393 | +236 | 浏览深度释放，双正 |
| 自然忠实 | 广告 0 点击、自然高度活跃 | 广告略放、自然加权 | +1530 | −249 | 收入增长以体验让渡为代价 |
| 低活沉默 | 广告自然都不互动 | 广告略放、自然加权 | +1383 | −51 | 挤占损失小，净收益 |
| 未打标 | 置信度不足 | 不调整 | −45 | +41 | 安全回退 |

关键机制证据：同样放宽广告扶持力度，人群一放宽幅度最大但自然侧损失最小，人群三放宽幅度最小却造成最大的自然订单流失——各人群对广告放宽的承受能力差异显著。

## 与影子价格线性演进路线的对照

该方案与对偶控制理论（dual mirror descent 等）解决的是同一问题，但更换了更新算子：

- **粒度**：对偶变量从标量 α 变成条件于人群的分段常数（K_p, δ_p），个性化维度由人群 Agent 用语义能力生成——这是传统「给特征、设护栏、跑 bandit」管线做不出的增量，因为分群依据（广告耐受度）无法用既有标签刻画。
- **更新规则**：梯度更新换成 LLM 推理驱动的黑盒寻优（与 OPRO 等大模型作优化器的工作同谱系），两阶段搜索代替纯 prompt 迭代。无 regret/收敛保证，靠大步长探测 + 小步长收敛 + 全局约束兜底。
- **状态承载**：人群 Memory 相当于离散化、文本化的对偶状态变量，承担 DMD 中对偶变量历史的功能。
- **未达请求级**：粒度为人群级、节奏为天级离线，未触及单请求实时影子价格；其后续规划（人群标识作为特征引入生成/重排模型）实质是让 Agent 退化为特征工程器、由模型侧接管个性化。

## 局限与开放问题

- 参数生效粒度是人群而非请求，同一人群内仍存在未利用的异质性；人群 Agent 的打标准确率 80%+，未打标人群无法受益。
- 边界探测在真实流量上试错，参数维度虽低（K/δ 两维）仍属线上探索，样本效率与安全边界未见分析。
- 无理论保证；约束满足依赖「收入提升、体验持平」的人工红线，而非带证明的可行性守恒。
- 收益分析显示人群三以体验换收入——若体验约束的权重随业务阶段变化，人群间的让渡边界如何动态设定是开放问题。
- 以上第 2–4 条为本人对文档的分析推断，非项目组自述。

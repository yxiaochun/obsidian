# 外卖搜索广告生成式混排一期：用自回归生成与DPO偏好对齐替代贪心混排

## 筛选与速览

- **一句话速览**：餐饮外卖搜索广告把混排从「NeuralAuction 排序 + 最密模版 + CPM 门槛」升级为**自回归生成模型端到端生成广告序**——参考 OneRec 的「预训练 + 偏好对齐」范式，beam search 采样序列后按 listReward 选优劣样本对做 DPO，线上整体曝光 pv +1.47%、广告收入 +0.96%（非首位收入 +1.78%），推全预计日均收入 +8.8 万，代价是耗时 avg +9.7ms。
- **最有价值的部分**：一是**收入来源对照实验**——在 base 策略上单纯降 CPM 阈值扩曝光（曝光 +1.46%）只换来收入 +0.17%、CTR -1.20%，而生成式混排同等曝光增幅下收入 +0.96%，干净地证明了收益来自外部性感知更充分的全局分配而非扩量；二是把 OneRec 的推荐生成范式迁移到广告混排时，对奖励函数、采样数、参考模型更新策略都做了消融式探索（N=10 即饱和、参考模型冻结优于周期复制）。
- **与我研究主线的关联**：这是「生成式推荐」思想在广告混排的直接落地——生成-评估到仅生成的范式切换、自回归 decoder 感知前序排列外部性、DPO 对齐非可微的业务奖励，与 gDNA 的整体拍卖路线形成同问题不同解法的对照。

## 背景与问题

外卖餐饮搜索广告之前的混排包含两部分：1）**广告序决策**：NeuralAuction 对精排后的广告 list 重排序；2）**广告位置决策**：由于此前发现调整广告密度和位置对自然侧体验指标影响不大，线上使用**最密模版 + 广告 CPM 阈值门槛**决策位置。流程：多位次 NeuralAuction 决策广告排序及计费 → 自然和广告队列按最密模版 Merge → CPM 门槛过滤掉 eCPM 较低的广告。

![[99_Attachments/图片/km-2753762610/基线混排决策流程图.svg]]

问题在于：NeuralAuction 只能感知**集合粒度**外部性信息，且分配时用每个候选的全局排序分**贪心分配**，难以实现整体最优。

## 业界调研与技术选型

重排/混排两种主流范式：**生成-评估范式**（先生成多条序列，再用评估器评估）与**仅生成范式**（直接生成最终序列）。仅生成范式能把生成和排序目标对齐并统一优化、避免级联误差、省去评估阶段的额外计算开销，模型复杂度上限更高——本次迭代选仅生成范式。

序列生成方法对比：

| 方法分类 | 举例 | 外部性信息 | 优化方法 |
| --- | --- | --- | --- |
| Neural Auction 方法 | DNA | set-encoder 提取集合粒度外部性 | 深层网络为每个候选计算排序分，neural sort 可微优化 |
| 非自回归生成 | NGA | generator 中自注意力提取候选集合粒度外部性 | 评估器计算奖励，策略梯度优化 |
| 非自回归生成 | NLGR | PDU 选位未考虑外部性；CRU 检索替换用自注意力提取当前排列外部性，但持续迭代替换时难以使用最终准确的排列外部性 | 构建邻居列表并计算相对奖励，明确优化方向 |
| 自回归生成 | CGA | 自注意力提取集合粒度外部性并保证排列不变性；GRU 准确感知前序排列外部性，自回归生成 | 评估器计算奖励，策略梯度优化 |
| 自回归生成 | OneRec | transformer decoder 自回归生成，准确感知前序排列外部性，输出语义 ID | 监督学习预训练 + beam search 采样构建偏好对算 DPO 损失做偏好对齐 |

相比 Neural Auction（集合外部性 + 贪心分配）和非自回归生成（排列外部性近似或不完整），**自回归方法能同时考虑集合外部性和准确的前序排列外部性**；优化方法上预训练 + 偏好对齐相比依赖奖励绝对值的策略梯度更稳定、预期效果更好。

## 技术方案：预训练 + DPO 偏好对齐

训练流程两部分：

1. **预训练**：监督学习训练生成模型，获得初步生成能力，且生成分布靠近线上 baseline；
2. **偏好对齐**：先 beam search 采样多条广告序列，与自然结果 merge 并计算每条序列的 reward，最后选优劣样本对计算 DPO loss 优化生成模型。

![[99_Attachments/图片/km-2753762610/偏好对齐训练流程图.svg]]

### 3.1 模型结构

业界生成式常用的 transformer encoder-decoder 结构。模型输入为广告候选队列 pctr、pcvr 等特征及上下文自然特征，输出广告 poi 最终排序结果：

- **encoder**：抽取上下文信息，生成特征交互后的候选 ad embedding；**不使用位置编码**以保证排列不变性；
- **decoder**：逐位次决策广告分配，自回归生成广告序列；输出经 sigmoid 后**与广告 bid 相乘**，保证分配概率关于 bid 单调递增；
- 自回归逐位次生成 top15 广告结果（最终单页上限 9 个广告，留与自然去重的 buffer）。

![[99_Attachments/图片/km-2753762610/生成模型架构图.svg]]

### 3.2 生成模型预训练

- **目的**：以真实线上广告返回的排序结果为目标，学习 base 序列结果分布，确保后续 beam search 能采样到高质量候选；预训练模型同时作为偏好对齐的参考模型。
- **数据**：全量线上请求。
- **loss**：交叉熵学习目标序列的概率分布：

$$
\mathcal{L}_{pretrain} = -\sum_{i\leq L}\log P(ad_i)
$$

- 线上尝试过直接用预训练模型不做偏好对齐，与线上 base 效果基本持平——**对齐阶段是收益的关键**。

### 3.3 偏好对齐

- **目的**：通过优化样本之间的相对偏好，让生成模型输出与期望奖励函数对齐，最大化生成结果对应的奖励。
- **数据**：全量线上请求。
- **流程**：
  1. **生成候选序列**：beam search 采样 N=10 条广告候选序列（离线尝试增大 N 未取得更好效果）；
  2. **评估奖励**：先用校准 ctr 模型校准 ctr，基于**后验曝光广告个数**设计页面整体奖励，更关注潜在可能曝光的广告：

$$
listReward=\sum_{i\leq T}\left(bid_i\cdot ctr_i+k\cdot ctr_i\cdot cvr_i\right)
$$

  其中 k 是 cxr 系数，T 是后验曝光广告数；
  3. **选取优劣样本对**：筛选 reward 最高的序列 $y_w$ 与最低的序列 $y_l$；
  4. **计算 DPO 损失**：

$$
\mathcal{L}_{\text{DPO}} = -\log \sigma\left(\beta\left(\log \frac{\pi_\theta(y_w|x)}{\pi_{\text{ref}}(y_w|x)} - \log \frac{\pi_\theta(y_l|x)}{\pi_{\text{ref}}(y_l|x)}\right)\right)
$$

  $\pi_\theta$ 是待优化的生成模型，$\pi_{ref}$ 是参考模型（使用预训练模型，对齐过程中**冻结参数**；离线尝试周期性将待优化模型参数复制到参考模型，未取得更好效果）。

## 实验效果与分析

线上 20% 流量观察 6 天（1.22~1.27）。影响范围：外卖餐饮搜索浮动位广告（slot=420）。

- **整体**：曝光 pv +1.47%，广告收入 +0.96%，CPC -0.19%，CPM -0.50%，CTR -0.31%，ROI -0.16%；
- **首位**：效果持平——受「首位求交」逻辑影响，本次迭代无法影响首位，符合预期；
- **非首位**：曝光 pv +1.68%，广告收入 +1.78%，CTR +0.51%，ROI +0.60%，订单数 +2.48%，gmv +2.40%；
- 预期全量后日均提升广告收入 8.8 万。

## 性能影响

自回归生成模型比 Neural Auction 基线复杂、耗时更高，午高峰 avg 9.1ms→18.8ms（+9.7ms），tp99 16.0ms→26.7ms（+10.7ms），但距线上超时时间（75ms）仍较远。

## 下一步计划

1. **修改计费方式**：目前沿用 NeuralAuction 模型计费，参考业界生成式拍卖方法，使用 regretNet 计算计费，提升激励兼容性；
2. **优化校准模型**：当前校准模型较为简单，优化后可进一步提升排序效果和收入。

> [!warning] 证据边界
> 这是美团内部 Launch Review 文档（外卖餐饮搜索浮动位广告 slot=420 单场景、6 天 20% 流量），数据不可复现、未独立复核。几个明确局限：① 首位因求交逻辑无法被干预，收益全部来自非首位；② 计费仍沿用 NeuralAuction 而非生成模型自身，激励兼容性未在生成框架内解决（列为下一步）；③ 偏好对齐只取 reward 最高/最低各一条序列，中间序列信息未利用；④ 整体 CTR -0.31%、ROI -0.16% 是曝光扩张带来的稀释还是排序变差，文档未做进一步拆分。原文含合并单元格表格，本笔记为简化转写，完整结构以学城原文为准。

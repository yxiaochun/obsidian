# UniROM：广告排序的端到端统一生成架构

## 论文信息

- 作者/机构：Junyan Qiu、Ze Wang、Fan Zhang、Zuowu Zheng、Jile Zhu、Jiangke Fan、Teng Zhang、Haitao Wang、Xingxing Wang；美团。
- 期刊/会议/年份：2025 年 arXiv 预印本，arXiv 2505.19755。
- 领域：计算广告、推荐系统、端到端生成式排序。
- 与我的研究关联：验证了广告排序从多阶段级联走向统一生成架构的工业路径，尤其是全候选外部性建模、拍卖约束训练和推理成本控制。
- 原文：[arXiv 2505.19755](https://arxiv.org/abs/2505.19755)；本地底稿 [[2025Meituan_UniROM.pdf]]。

## 一句话创新点

把 LBS 广告的召回、预排序、排序与拍卖统一为一个非自回归生成模型，用混合特征服务降低全候选特征成本，用可学习聚类注意力和拍卖感知训练在 $N \approx 10^5$ 候选池内建模序列级外部性。

## 核心问题

工业广告系统的多阶段级联架构（MCA）先从约 $10^5$ 候选逐步过滤到约 $10^1$ 展示序列，带来三类问题：

1. 召回、预排序、排序与拍卖的优化目标和模型能力不一致，上游过滤误差会传导到最终展示。
2. 传统排序多按候选独立打分，难以建模候选之间、候选与页面位次之间的外部性。
3. 直接对全候选做显式交叉特征和多对多注意力会产生过高的存储、传输与计算成本。

论文的正式任务是在满足激励兼容（IC）和个体理性（IR）约束下，从全量候选广告集中生成最大化平台收入的 $K$ 个广告序列。

## 七问笔记

| 问题 | 回答 |
| --- | --- |
| 研究背景 | 美团 LBS 广告受限于 MCA 的逐级过滤、阶段目标不一致和独立打分；已有统一训练方法仍保留多阶段架构，生成式推荐工作则多受自回归推理延迟和广告拍卖目标约束。 |
| 研究目的 | 用一个端到端模型直接从全候选广告池生成广告序列，同时兼顾用户行为、平台收入、广告主效用与拍卖约束。 |
| 创新点 | 以 HFS、RecFormer、AucFormer 和两阶段训练共同解决全候选广告生成的特征成本、外部性建模与拍卖对齐问题，并给出工业规模落地证据。 |
| 研究方法 | HFS 将候选广告特征放入本地 RAM/SSD、用户与上下文特征单次 RPC 后广播；RecFormer 用 Global Cluster-Former 建模候选和用户序列，用 Mid-fusion Interest-Former 做目标注意力与上下文注意力；AucFormer 用非自回归分配矩阵、排列感知评估器和支付网络；训练先做行为信号预训练，再做 RLAF 与支付网络优化。 |
| 实验数据 | 工业数据集来自 2024-04 到 2024-10 广告日志，含 2 亿请求、200 万以上用户、近 1000 万广告；前 200 天预训练，抽样 50 天后训练，最后 14 天测试。LBS 场景单请求最多 $N=100{,}000$ 个候选，$K=5$ 个广告位，训练采样 $N_s=2995$。 |
| 结果结论 | 离线工业数据上，UniROM 的 Recall@50 为 0.513、AUC 为 0.754、eCTR 为 6.652%、eRPM 为 217.1、IC 指标 $\Psi$ 为 2.3%，分别超过 MCA 和 FS-LTR；消融显示 GCF、MIF、AucFormer/RLAF 都有效。表 4 的线上 A/B 显示 CTR +5.2%、RPM +13.6%、ROI +3.1%、RT +2.2%，但第 5.6 节正文写为 CTR +3.8%、RPM +11.2%、ROI +3.1%。 |
| 总体评价 | 证据支持 UniROM 在该 LBS 广告场景中能显著超过所测 MCA 与 FS-LTR，并且聚类注意力与拍卖训练是关键；但摘要、正文与表格的线上数字不一致，公开基准缺失，七天 A/B、单域场景和工业数据不可迁移性限制结论的外推。 |

## 方法拆解

- **Hybrid Feature Service（HFS）**：候选广告数量大但更新低频，因此只保留核心类别特征，把一阶广告嵌入放入本地 RAM/SSD；用户行为、属性和上下文每次请求只做一次 RPC，随后广播给全候选。被省略的数值与显式交叉特征交给后续隐式交互结构恢复。
- **Global Cluster-Former（GCF）**：用可学习聚类矩阵把 $N$ 个键值压缩成 $N_c \ll N$ 个代理 token，再把原始 query 对聚合后的 key/value 做多头注意力，把候选/序列自注意力的 $O(N^2 d)$ 降到 $O(NN_c d)$。
- **Mid-fusion Interest-Former（MIF）**：在 GCF 的若干中间层插入跨序列交互；候选到用户行为做 target attention，用户行为到候选集合做 context attention。相比把每个目标广告加入行为序列的 early fusion，它避免重复长序列交互，同时比 late fusion 更早引入候选相关上下文。
- **AucFormer**：分配生成器用 slot token 与候选广告表征计算 $N \times K$ 分配矩阵，softmax 中加入可学习的正 bid 偏置，逐槽贪心选择并屏蔽已选广告；评估器根据最终排列估计 pCTR/pCVR；支付网络以 sigmoid 输出支付率并乘 bid，保证 $\text{payment} \le \text{bid}$。推理只部署生成器和支付网络。
- **训练策略**：预训练以请求为样本，热度采样加入未曝光广告，用曝光点击、平台内其他入口点击及同 session 自然形态点击作为监督；后训练先训练排列感知 reward model，再冻结评估器和 RecFormer，用 RLAF 优化生成器，最后用拉格朗日对偶优化支付网络以平衡收入与事后后悔。

## 实验证据

- **离线主表（表 1）**：MCA 为 Recall@50 0.289、AUC 0.741、eCTR 6.043%、eRPM 185.2、$\Psi$ 9.4%；FS-LTR 为 0.426、0.743、6.140%、194.9、9.1%；UniROM 为 0.513、0.754、6.652%、217.1、2.3%。UniROM 相对最强基线的 Recall@50 提升 20.4%，AUC 提升 1.48%，eCTR 提升 8.3%，eRPM 提升 11.4%。
- **架构消融（表 2）**：去掉 GCF 后 eCTR/eRPM 分别下降 1.3%/1.1%；去掉 MIF 下降 2.5%/2.1%；去掉 AucFormer 并改用 GSP 下降 2.1%/4.2%。这说明全局外部性、深层兴趣建模和拍卖感知分配/训练都有效。
- **交叉特征消融（表 3）**：移除 94 个特征中的 18 个交叉特征后，MCA AUC 下降 0.8%，UniROM AUC 仅下降 0.3%；进一步移除 context attention、target attention 或整个 MIF 时，UniROM AUC 分别下降 0.9%、1.1%、1.7%。这支持 MIF 在显式交叉特征不可用或被裁剪时能部分恢复交互信息。
- **Scaling 与成本（图 5）**：加深 RecFormer/AucFormer 层数带来渐进收益，但超过阈值后进入平台期；FLOPs 与性能正相关且边际收益递减。作者把平台期归因于固定数据规模和序列长度。线上处理候选数比 MCA 排序模型多数百倍，但平均响应时间增加 5 ms（相对 +2.2%）。
- **线上 A/B（表 4）**：2024-11-18 到 2024-11-24，对比全量部署 MCA，表 4 报告 CTR +5.2%、RPM +13.6%、ROI +3.1%、RT +2.2%。第 5.6 节正文却写 CTR +3.8%、RPM +11.2%、ROI +3.1%。两组数字不能直接互相替换。

## 关键图表解读

- **图 1**：左边 MCA 显示候选规模从约 $10^5$ 逐级降到约 $10^1$；右边 UniROM 直接从全候选生成广告列表，把点独立 eCPM 改为列表级收入与排序目标。
- **图 2**：完整链路是 HFS -> RecFormer -> AucFormer。GCF 先分别建模候选集合和用户行为，MIF 桥接两者；AucFormer 再做分配、排列感知评估与支付。
- **图 3**：传统 RFS 对多阶段反复 RPC，特征空间难以支撑全候选；HFS 把广告嵌入本地化、把高频用户特征集中为一次请求级广播，用计算驱动替代显式特征工程。
- **图 4**：early fusion 有完整交互但每个候选都要重复处理长序列；late fusion 廉价但用户表征与目标无关；mid fusion 通过中间层跨注意力在成本与表达之间取得折中。
- **图 5**：Scaling 曲线说明 UniROM 有可扩展性但本文设置已经出现饱和，不能证明无限扩容会继续显著提升。

## 批判性分析

- **动机是否充分**：充分。阶段目标冲突、样本选择偏差和外部性是广告系统真实问题；论文将候选池收敛到同城后，全候选生成在 LBS 场景内有现实可行性。
- **对比是否公平**：与 MCA、FS-LTR 使用相同数据与多指标比较，FS-LTR 是合理的强基线；但论文未提供每个组件的完整超参数搜索结果和实现细节，工业基线的特征工程与系统优化程度仍难以完全核验。
- **实验是否完整**：消融覆盖主要模块，交叉特征分析有针对性；缺少公开基准结果、更大候选池与更长线上周期。摘要和结论宣称 public benchmarks，但实验章节只给出工业数据集，这是明显证据缺口。
- **指标是否合适**：离线用 Recall@50、AUC、eCTR/eRPM 和事后后悔构造的 $\Psi$ 覆盖排序、收入与拍卖约束；AucFormer 自身担任离线 replay 的评估器，导致 eCTR/eRPM 的离线收益部分依赖模型内部评估假设，最好与独立校准结果或在线真实反馈交叉验证。
- **换位思考**：我会把公开数据集、线上数字一致性和支付网络校验放在正文优先级更前的位置；实验上可补充真实曝光重放、独立 pCTR 校准、更长 A/B、城市间泛化、竞品分配机制与 IC 敏感性扫描。
- **优点**：系统设计完整，算法与工程约束贴合；HFS、GCF、MIF、NAR 生成和 RLAF 各自对应明确瓶颈；线下与线上证据覆盖效果、成本和广告主 ROI。
- **不足**：线上主结果正文与表格冲突；工业数据、商业脱敏和七天 A/B 限制可复核性；$N_c$ 的最佳值依赖数据分布，论文未讨论新广告、候选漂移和聚类失效场景；附录的 IC 只是近似差分约束，没有给出部署期真实事后后悔分布。

## 值得追踪的引用

- HSTU：验证推荐序列转换器的缩放路径，也是 UniROM 用深度而非显式特征换表达能力的参照。
- CGA：UniROM 的分配、支付网络和 IC 事后后悔约束直接参考该生成式拍卖方向。
- FS-LTR：论文最关键的离线基线，代表仍保留多阶段架构但做全阶段一致性训练的路线。
- OneRec：同样追求召回与排序统一，可与 UniROM 比较自回归/非自回归生成和广告拍卖约束的差异。

## 复现清单

- **数据**：论文工业数据集不公开；摘要与结论提到公开基准，但实验章节未给出对应数据集、划分和结果。必须先解决数据可得性问题。
- **代码**：论文没有提供代码链接或开源承诺。
- **环境与超参数**：可从论文获得 $L=1000$、$d=128$、GCF/MIF 层数 $m=6$、AucFormer 层数 $m_e=3$、MIF 间隔层数 $m_k=2$、4 个注意力头、$N_c=128$、MLP 128/32、Adam、学习率 $10^{-3}$、batch size 128；但缺少精确特征表、baseline 完整实现、奖励模型收敛判据、RLAF 采样与对偶系数调度。
- **改良设想**：把 $N_c$ 与候选分布自适应联动；在 RLAF 中加入长期广告主效用和延迟反馈约束；用独立校准或反事实评估替代仅由内部评估器支持的 eCTR/eRPM；引入城市迁移、冷启动广告和竞价环境扰动测试；对 payment network 报告真实事后后悔和 IR 违反率。

## 结构判断

> [!warning] 证据边界
> 本文是 arXiv 单篇工业论文，结果含商业脱敏，且线上主指标在表 4 与第 5.6 节正文之间不一致。结论应限定在“美团 LBS 广告实验与七天 A/B 的表现有效”，不能直接外推到其他广告市场、通用推荐、更长周期或公开基准。
